## 本轮处理

统一使用 `native_process` 标记，将仍在 pytest 主进程中创建真实 Tk 根窗口的 15 个参数化测试实例交给独立 Python 进程。拦截发生在 fixture setup 之前，因此模块级 `quote_window` 也不会留在父进程中。已有自行启动子进程的测试保留原路径。

子进程运行同一个 nodeid 的正常 pytest setup/call/teardown。没有整项重试、跳过或降低原断言；退出失败、fixture 错误、断言错误及超时均使父测试失败，并保留子进程输出。使用短临时目录保持 Windows 路径长度安全。替换先前盘后统计单例中的临时环境变量和重复启动代码。

这是测试运行边界的修复，不是对 Tcl 上游原因的最终证明。它减少测试间共享 Tcl/ttkbootstrap 状态，不能保证消除任何机器上的所有 Tcl 安装或系统级故障。持续失败必须继续暴露。
