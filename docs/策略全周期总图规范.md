# 策略全周期总图规范 V1

## 用途

策略全周期总图用于把一个策略从背景出现到交易结束放在**一张连续图**里。交易员应能沿时间从左向右读完，不需要在多页、卡片或标签之间拼接过程。

本规范适用于 Aplus 现有及以后新增的所有策略。它只规范研究表达和验收方式，不替代策略代码、回测报告或人工计划。

**适用边界**：本文的六段骨架用于研究教学总图，不要求实际行情主图增加六段标题或所有假设分支。实际 K 线的短标签、选中机会、历史信号与布局参数统一见[图表工作台策略标注契约](TradingView图表重构方案.md#strategy-annotation-contract)，不重复维护另一套生产视觉规范。

## 固定骨架

每张总图按下列六段从左向右展开；策略没有某一段时保留位置并写明“不适用”，不要改变阅读顺序。

1. **背景**：趋势、区间、缺口、均线关系等成立前提。
2. **结构变化**：突破、反转、测试或其他使策略进入观察状态的结构。
3. **形态准备**：策略专属的 H1/H2、回调、二次测试等候选条件。
4. **信号与计划**：信号 K、确认时点、入场、初始止损和初始目标。
5. **等待与成交**：挂单存续、失效、超时、实际触发和未成交分支。
6. **持仓与退出**：移动止损、分批止盈、结构退出、期满退出及最终结果。

图内必须同时画出主路径和所有会使机会结束的关键分支。不能只画“理想盈利路径”，也不能把“信号出现”“挂单触发”“模拟成交”合并成一个事件。

## 一张图中必须说明的内容

- 策略名称、周期、版本或规则口径。
- 每个关键点的名称、发生顺序和确认时刻。
- 系统当前实际执行的入场、止损、目标与退出逻辑。
- 哪些阶段已经由盘前匹配、盘后回测或策略迭代覆盖。
- 哪些内容只是 PA 理论解释，哪些是待验证的研究假设。
- 数据或画法为示意时，明确写“非真实比例／合成路径”，不能让示意样本冒充真实回测。
- 当前已由用户确认的研究问题。默认不替交易员预设其他研究问题。

## 视觉规则

- 使用一张横向连续价格路径作为主体；阶段标题固定在上方，说明贴近对应事件。
- 本教学总图的路径：已实现规则和已发生路径用实线；尚未实现、待验证或可能发生的后续路径用虚线，并在文字中写明状态。实际 K 线的 Entry／SL／TP 角色线型另遵守图表工作台契约，不能仅凭虚实判定实现或成交状态。
- K 线继续使用行情本身的涨跌颜色。策略文字、引线、箭头及锚点统一使用灰白等中性色，避免红绿与行情方向混淆。
- 引线指向 K 线的水平中心和对应价格，但在线端与实体或影线之间保留明显间隙，不能看起来像 K 线的一部分。
- 价位线可按 Entry、SL、TP 角色着色，同时用不同线型和文字独立识别；结构文字、锚点、引线继续中性灰白。角色色不表示行情涨跌，也不把触发当成交。
- 阶段之间保持连续时间方向。为说明结构允许压缩时间或价格比例，但必须标注“示意，非真实比例”。
- 一个 tick 必须来自品种规则，不能统一写成 0.01。若图中忠实展示现行代码的固定值，应明确标注“现行代码固定值”。
- 在常用桌面宽度和窄窗口下，标题、关键点、分支结局不得被裁切或互相遮挡。

## 三类口径的标记

| 图内标记 | 含义 | 示例写法 |
|---|---|---|
| 当前规则 | 软件当前实际使用 | “当前规则：突破信号 K 高点后入场” |
| PA 解释 | 理论上用于理解结构 | “PA 解释：低点抬高，卖压减弱” |
| 研究假设 | 尚需回测比较 | “研究假设：改用最近强突破腿底部止损” |

研究假设不得写成策略已经具备的能力。策略本体的新版本规则标明“当前规则”和版本号；只有适配层或研究层附加的筛选才标为“Aplus 额外筛选”。

## 各板块如何使用

- **盘前任务**：在候选详情中说明当前信号位于总图哪一段，以及下一步等待什么。
- **盘后回测**：按总图顺序回放信号、挂单、成交、持仓和退出，不改变历史可见边界。
- **策略迭代**：从总图中选择一个明确问题做方案对照；同一实验只改变声明的假设，其余条件保持一致。
- **交易管理**：只接收人工确认后的实际交易，不把研究路径或模拟成交写成真实持仓。

## 新策略出图验收清单

- [ ] 一张图完整覆盖背景至退出，六段顺序一致。
- [ ] 信号、计划、触发、成交和退出没有混称。
- [ ] 失败、失效、超时和未成交分支完整。
- [ ] 当前规则、PA 解释和研究假设可以一眼区分。
- [ ] 中性标注不与红绿 K 线混淆，引线不延长实体或影线。
- [ ] 所有 tick 和价格精度符合品种；示意图已声明非真实比例。
- [ ] 研究问题来自已确认需求，没有替交易员预设结论。
- [ ] 桌面常用尺寸和窄窗口均无裁切、遮挡和非必要换行。
