# Gap Pinbar、AWIL 与 Structural Gap 快速拒绝灰度

## 使用影响

三个策略默认均为 `OFF`。不开环境变量时，不构造灰度控制器，策略调用、缓存身份、回执和事件完全沿用原路径。研发集中在同一模块和 PR，但生产授权、缓存、熔断及回退逐策略独立，一个策略的差异不会关闭或污染另一个策略。

快速拒绝仍在行情文件 SHA-256、范围和历史质量门禁、公共指标准备之后执行。冻结策略、`frozen_manifest.json`、Entry、SL、TP、评分和机会身份均不修改。GAP H2 不在本功能范围内。

## 三项正式信号必要条件

- **Gap Pinbar**：末根必须同时满足下影占比至少 40%、收盘位置至少 50%、当日最低价刺破 EMA20 且收盘重新站上 EMA20。门禁只证明不满足时末行 `signal_gap_pinbar` 不可能为真；首次刺破、历史突破和缺口存活仍由原版判断。
- **AWIL**：末根必须为阳线、收在全振幅顶部 2%、最高价突破前高且最低价仍在 EMA20 上方。H2 四阶段状态、历史波段组和整段 EMA 条件仍由原版判断。
- **Structural Gap**：末根必须低点不再创新低、高点突破前高、为阳线且收盘高于前收盘。历史缺口、回调窗口、测距目标、去重和动态规则仍由原版判断；若发现 `config/gap_optimized_rules.json`，当前绑定直接回退原版。

三套门禁先核对同一 OHLCV、日期顺序及公共 `ema20`、`atr`、`close_loc`、`is_bullish` 的类型、有限值和精确计算结果。文本污染、陈旧指标、未知环境或任何校验异常均执行原版，不会记成正常无信号。

## 模式、授权与比例

每个策略均支持：

- `OFF`：完全执行原版，默认值；
- `SHADOW`：门禁拒绝后仍执行原版并对拍，只采用原版结果；
- `CANARY`：比例表示获准采用快速拒绝的样本比例，其余继续原版对拍；
- `ACCELERATED`：比例表示保留原版核验的样本比例，其余采用快速拒绝。

环境变量分别为：

```text
APLUS_GAP_PINBAR_FAST_REJECT_MODE
APLUS_GAP_PINBAR_FAST_REJECT_APPROVED_BINDING
APLUS_GAP_PINBAR_FAST_REJECT_CANARY_RATE

APLUS_AWIL_FAST_REJECT_MODE
APLUS_AWIL_FAST_REJECT_APPROVED_BINDING
APLUS_AWIL_FAST_REJECT_CANARY_RATE

APLUS_STRUCTURAL_GAP_FAST_REJECT_MODE
APLUS_STRUCTURAL_GAP_FAST_REJECT_APPROVED_BINDING
APLUS_STRUCTURAL_GAP_FAST_REJECT_CANARY_RATE
```

CANARY/ACCELERATED 必须使用目标机器即时生成的对应 `current_binding_id(strategy_id)`。绑定覆盖精确冻结发布、计算闭包、正式输出适配层、Service、本模块、扫描缓存、持久化契约、运行环境以及 Structural Gap 动态规则状态。任一变化都会使旧授权失效并安全回退；CI 通过不等于获得生产授权。

## 熔断与回退

SHADOW、CANARY 保留原版的样本或 ACCELERATED 抽样样本，一旦出现原版业务异常或正式 payload 差异，只熔断当前策略和当前绑定，保存样本摘要、异常或原始结果证据，并停止写入该加速身份的完成缓存。

单独回退任一策略，只需把相应 `..._MODE` 删除或设为 `OFF`。熔断证据不得在未调查前清理并重开同一绑定。

## 复核命令

```powershell
python tools/validate_gap_family_fast_reject.py `
  --source-home "<Aplus 数据仓>" `
  --temp-root "<独立临时目录>" `
  --output "<独立输出目录>\gap-family-validation.json"
```

工具使用 SQLite `mode=ro` 快照事务读取源仓、逐文件复核 SHA，并只向独立临时 Store 写入扫描结果；不联网、不修改正式 runtime。
