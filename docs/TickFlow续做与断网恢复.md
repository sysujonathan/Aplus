# TickFlow 日常续做与断网恢复

## 用户操作

日常仍只需点击“一键”。本轮目录和日历凭证有效时，已保存且就绪的行情不再下载；缺最新尾部或整份行情的股票进入普通批量增量通道，真正缺中间交易日的股票才进入当前扫描输入内的定向补拉。元数据只用于选择下载通道，不能证明可扫描；文件路径、SHA-256、交易日、复权衔接、质量及当前扫描资格仍实际核验。日／周输入门槛和已有长历史保持不变。

TickFlow 批量预取或额外历史取数遇到明确的临时传输故障（超时、SSL意外断开、连接重置／中断）时，本次普通一键／续做行情任务共用**一次**自动恢复额度：先记录原持久冷却，显示“临时断网，等待N秒后自动续做”，冷却真正结束才重复失败请求，随后继续尚未完成的股票。已经保存的股票不重头下载。等待可随时终止；单次等待最多120秒，冷却被延长或出现限制访问时停止，不清除冷却状态。网络请求仍串行、每批最多100只、沿用至少1.5秒间隔，未增加供应商并发。

403、429、黑名单、明确限制访问、无法识别的错误、HTTP服务错误、证书验证失败、响应格式异常和补拉无改善**不自动重试**。显式手工补拉、强制／完整历史入口保留原单次请求语义。一次恢复仍失败就结束本来源更新，保留数据和完整错误；其他来源继续，当前来源只扫描实际已核验的合格标的。再次点击会重新核对冷却和剩余工作，不能保证供应商尚未发布的数据立即补齐。

## HTTPS 证书连接

TickFlow 连接只使用经过安全检查的 `certifi` 证书库，解决部分 Windows 机器缺少签发机构信任链而无法更新的问题。锁定版本为 `2026.10.23`，实际运行版本不得低于该版本；旧版或版本无法确认时明确停止，不只依靠锁定文件声明。连接不合并系统或 `SSL_CERT_FILE` 指定的旧信任库，避免重新带入已撤销信任的 CA；不修改系统证书、全局 SSL 设置或其他数据源。

本修复升级既有证书依赖，`requirements.txt` 和锁定清单均有变化，原更新器会按既有安全门禁要求人工安装。维护者须同时更新实际运行环境的证书依赖和发布代码，再重启；仅替换代码、仅修改锁文件或继续使用旧进程都不算完成升级。无需逐次设置环境变量。此项没有绕过项目原有的人工安装要求。

服务器证书和域名仍严格校验。证书过期、域名不符、不受信任、本地证书库损坏或仍包含受影响的 `emSign ECC Root CA - G3` 时停止，不降级为跳过证书校验；原冷却及证书错误不自动重试的规则保持。已存在的冷却须自然结束，不删除失败记录。行情和策略加速授权相互独立，本修复不生成或续签授权。

## 候选数量的含义

“行情未齐未扫描”不是“策略计算后无信号”。一键完成摘要标出未扫描数量，当前日期仍有缺口时顶栏显示“信号…部分”，详细窗口保留股票及缺日原因。两源结果不一致时先比目标日期、策略版本和实际参与扫描的股票，再比较价格；不能仅比较候选总数判断哪个源更准，也不能把BaoStock价格接入TickFlow快照。

本轮只读诊断定位到2026-10-15的002382：BaoStock当日行情完整并命中GH2，TickFlow所在批次SSL传输中断，行情仍止于10月14日而被排除。这是输入覆盖差异，不是同一份输入下GH2判定矛盾。新增隔离测试复现这种故障形状，不修改冻结策略，不将合成形态当作真实信号验收。

## 本地性能

续做不再先为全市场尾部缺失逐份解析CSV并规划历史补拉区间；普通增量只处理实际缺尾部／缺快照的股票，已记录补拉无改善、明确停牌及身份异常不自动纳入。当前扫描内中间缺口最多再做一次有界修复，网络失败或冷却后不会套用该修复流程发出额外请求。

盘前工作线程的独立SQL查询采用只读连接，不等待其他源的文件序列化锁；写入仍按同一文件锁→数据库短事务顺序提交。事务内读取使用本事务连接，保留读己之写和失败回滚。没有修改Store、schema 8或SQLite日志模式。

文件读取审计保留每条路径、原始时间和字节数，每100条合批提交，正常／失败／取消收尾均刷新剩余记录；进程崩溃可能丢失最后不足100条纯读取日志，不影响即时提交的写入凭证、行情、质量和覆盖。父任务只保存续做数量摘要，完整代码清单留在子回执；TickFlow累计进度约每秒保存，错误及收尾强制刷新。行情仍逐股提交，不因节流丢失已存快照。

子回执新增本地读取耗时、写锁等待和连接数；批量尝试数／耗时包括失败请求，自动等待单独记录在transport_recovery，不把等待计为批量网络响应时间。逐股处理耗时仍可能包含复权衔接变化触发的额外同源网络，不能简单等同磁盘耗时。

## 腾讯历史行情退出

“一键”来源菜单仅保留BaoStock和TickFlow。旧的多源选择过滤掉腾讯；如果原来只选腾讯，则回落到当前可更新来源（当前也是腾讯时选BaoStock），至少保留一个有效选择，不删除旧偏好或记录。桌面／Web／Service的腾讯历史更新与价格补拉入口均停用；历史来源仍可查看既有快照、候选、扫描和研究，三源既有存储格式不变。腾讯持仓即时取价与历史下载是独立线路，本轮不修改。

## 验收边界

所有自动测试使用临时数据仓和虚拟时钟，无真实供应商下载、正式账本写入或运行目录安装。验证一次传输恢复、持续失败封顶、等待终止、冷却延长／限制到来、明确限制不重试、IPC错误标记、两源独立、尾部批量／中间缺口分流、读取与写入锁顺序及原记录可读。代码回归和CI通过不替代真实网络与长期使用验收。
