# 三源历史缺日核验

## 交易员操作

先看“可扫描／暂不扫描”数量，直接扫描合格股票，不用等全部缺口解决。

日线“更新行情”及日线“一键盘前”会自动处理当前板块内、日／周实际扫描输入中仍受阻的全部缺日，不再每次只取5只，也不再需要手动“核验缺日”。先完成普通价格更新，再查询尚无事实的逐日交易状态，最后只对明确有交易却缺价格的股票补拉当前来源价格。复用日线缓存时同样执行。明确事实跨来源、跨重启复用；停牌日不补造K线，当日停牌不参与当日可交易扫描。

状态查询串行，请求间隔至少1秒，单次登录／查询最多5秒，不再设20秒整批截止；首次有数百只积压时可能需要数分钟以上。已有BaoStock连接或冷却时不争抢连接；网络错误停止本轮状态查询，保留已完成证据。未知响应24小时退避，新增缺日不受旧退避阻挡。退出或取消后不在后台继续跑，下次日线任务从已保存事实接续；未完成请求不会被记为“已核验”。每批只集中重核受影响股票的日／周资格，不对每个响应重复全市场校验。

周线任务、显式补拉、全历史研究及强制刷新不额外启动自动状态查询。日线任务同时消化周线实际输入中的历史缺日。右下角沿用原来的简洁任务状态，不增加核验阶段、证券代码或缺日解释；详细查询、错误及补拉结果保存在任务回执、事件和缺口详情中。“继续补拉”仍保留，供显式重试价格使用。

- 明确历史整日停牌：该日不应有交易K线；不补造价格，股票其他输入合格时可扫描。
- 明确当前日停牌：本日不进入可交易扫描范围，不要求补造当天K线。
- 明确正常交易却缺K线：自动定向补拉所选来源的价格，仍缺则继续排除。先修已完成周线输入，再仅修仍未齐的日线输入，每周期最多一轮，不无限重试；同一日期、价格快照及交易事实的已完成补拉不会反复请求。
- 没有返回明确状态：仍待定，不能用“三源同时缺日”当成证明。
- 日／周K不足125根：按所选周期排除，停牌证据不能豁免根数要求。

“忽略提醒”只减少待处理提醒，不改变扫描资格；“暂不扫描”数量一直显示。更早历史仍独立核验，不以当前扫描合格冒充全历史完整。

上述入口调整针对安装版桌面。旧网页研究端和`verify_status`后端接口保留兼容，不能据此在桌面另建一套任务。

“当日处理”是对全部候选发起有界处理，不是承诺所有外部故障当日归零。身份仍按现有目录和明确证券身份事实核对：已知旧代码／未在市身份不请求价格或当作停牌，不把新代码的价格移给旧代码；无依据的身份变化仍保留异常。根数不足、文件损坏或未知状态均不能靠停牌核验豁免。补拉成功或无改善都不自动证明停牌。

## 技术边界

`trading_status.py`保存不含开高低收价格的不可变状态回执与schema-8 meta索引。只接受明确的`tradestatus=0`；零／空成交量不单独构成证据。日期、证券身份、状态、重复行及停牌日非零成交量均校验。缺失响应不会补写状态，冲突或文件校验失败不放行。

`status_review.py`经Service单任务队列执行；核验集合由当前范围、来源、周期与实际受阻日期决定。目录不明、身份问题、文件损坏及根数不足不能通过此入口豁免。三源扫描共用最近300根输入与至少125根已完成K线的资格检查，范围核验失败阻断整批，逐股问题只排除该股并回执部分完成。

`status_maintenance.py`在普通日线价格同步返回后、额外缺口补拉前调用同一状态核验管线，用现有meta保存已完成未知响应的退避时间、每来源父任务去重及价格补拉指纹，不新增表或后台调度器。多源共享状态事实，各来源独立处理自己的价格。供应商连接仍经原可终止子进程、系统互斥及冷却保护；未结束的请求不写成功指纹。状态／价格变化后集中重算受影响股票的资格，实际扫描仍执行独立门禁。

历史补拉合并后，先按与保存快照相同的顺序校验，再生成日线窗口；日线最近300根按日期排序。旧质量摘要缺少窗口版本时，在后台从原快照重算一次；不改写旧CSV、旧观察或策略结果，GUI缓存未准备好时仍保守提示待核验。

BaoStock后续正常下载将明确状态另存为事实，不丢弃停牌证据；连接、限速、失败预算及同源增量价格机制不变。现有旧快照不因缺日被倒推为停牌，只能另行核验。证据变化使相关股票的旧质量摘要失效；实际扫描重新核验后才复用，GUI不在主线程联网或遍历历史价格。

三源价格、快照、覆盖及人工忽略选择仍分别管理。不复制其他来源价格，不修改冻结策略、不自动下单、不重写历史扫描成果或交易账本。研究仍要求自己的真实历史与缺口核验；腾讯不复权风险不因停牌核验消失。

## 2026-10-10 真实核验

首先核验2026-10-09三源MTR差异中的26只股票、144个缺日，全部明确停牌；用三源各自真实缓存只读复验，26只全部通过日线资格检查。随后覆盖当前扫描的324只历史缺日及10只尾日落后标的，共1,510个缺日，全部返回明确停牌状态，正常交易0、未知0。首批26只复用事实，后续仅查询308只，没有重复核验，也没有下载价格。10只尾日停牌仍不参与当日可交易扫描。

公开公告抽查也相符：[600084于2026-04-28停牌一天](https://dataclouds.cninfo.com.cn/shgonggao/hsomarket/2026/20260427/9b19711c7fcb4bea905ee14d457cf3cb.PDF)、[002235于2025-12-01起停牌](https://static.cninfo.com.cn/finalpage/2025-12-01/1224837963.PDF)并于[12月8日复牌](https://static.cninfo.com.cn/finalpage/2025-12-08/1224856378.PDF)。公告抽查不冒充144日公告逐条复核。

核验在独立运行目录完成；供应商状态证据不冒充逐日公告复核，也不代表全市场更早历史已核验。后续按当前输入缺日优先、状态事实优先、公告补充未知的顺序完善；不是无期限重拉所有历史价格。
