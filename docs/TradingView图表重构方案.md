# TradingView 图表工作台重构方案

本文件是[项目视觉规范](项目视觉规范.md)下的图表工作台子规范；跨策略的实际 K 线标注只在本文“策略图表标注”一节维护。范围与逐项验收以 [TV 原始需求与验收清单](TV原始需求与验收清单.md) 为准。用户仅暂缓分钟数据源及其依赖功能；本文的设计建议和已有代码不表示交易员验收完成，未完成的非分钟功能继续在本次范围内。

## 交易员使用结论

策略扫描与自选标的应作为选股导航，主工作区默认是一张可以持续分析的完整图表。交易员从 GAP H2 等策略结果点入股票后，先核对策略证据，再在同一张图上画趋势线、缺口、斐波那契、通道和多头仓位，并设置提醒。切换到其他股票或下次打开时，原标的的人工图形、指标参数、缩放位置和提醒仍在。

因此桌面不再把“策略提醒挂单页”和“A++ 图表”设计成两套割裂入口。候选、关注、持仓、已清仓共用同一个图表内核；右侧面板只改变上下文，不更换图表操作逻辑。多图保留为快速扫描视图，选中任意一格后进入同一套单图分析工作区。

## 页面结构

### 顶部全局工具栏

从左到右依次为标的、周期、图表类型、指标、布局、提醒、回放、撤销／重做、布局名称、快照和侧栏开关。图标全部使用统一线性 SVG，视觉尺寸 20–24px，点击热区不小于 36px。

当前只有日、周、月真实行情时，5 分钟、1 小时和 4 小时保留位置但禁用，并在悬停时说明“尚未接入分钟行情”。只有接入真实分钟源或用户导入并通过校验的分钟 CSV 后才可用 Bar Count。

### 左侧绘图栏与常用浮条

左侧保持 TradingView 的肌肉记忆顺序：光标、趋势线、斐波那契、几何形态、文字、图标、测量、框选放大、框选缩小、磁铁、锁定、显隐、移除和收藏。常用浮条固定包含用户日常使用的 11 项：斐波那契、多头仓位、水平射线、趋势线、空头仓位、矩形、上下箭头、箭头、多段折线和平行通道。浮条通过左侧六点抓手拖动并保存位置。

工具采用明确状态机：空闲、准备落点、绘制中、对象选中、整体拖移、锚点拖动、框选缩放、平移和回放互斥。默认完成一个图形后自动回到光标，不连续绘图；多段折线逐点落位并双击完成。磁铁打开时，仅在端点靠近K线时吸附该根K线的开高低收。Esc 结束绘制，Delete 删除选中对象，Ctrl+Z／Ctrl+Y 撤销或重做人工图形；策略证据不进入人工撤销栈。

### 主图

默认主题按用户实际 TradingView 页面：`#0B0B0B` 背景、`#1F1F1F` 网格、白色上涨 K、`#2962FF` 下跌 K、`#FF9800` EMA20。右侧价格轴与底部时间轴直接参与交互：拖动价格轴改变纵向比例，拖动时间轴改变横向密度，双击恢复自动范围；鼠标所在位置显示十字线、价格、日期和对应 OHLC。主图区空白处按住左键直接平移，方向与图形跟手一致。鼠标进入图表中下部中央约 500px 宽、时间轴上方约 110px 高的区域时，临时显示缩小、放大、向左、向右和重置五键；离开区域后隐藏，不遮挡日常标绘。

“重置图表视图”恢复横向 204 根实际K线、最新K线右侧约 12 根K线宽度的观察空间，同时恢复纵轴自动范围。滚轮、时间轴拖动、底部加减和框选缩放都改变可见根数，因此K线实体和影线宽度必须同步变化；不能只放大坐标文字或绘图覆盖层。

图上信息分为五层，层次不可混用：

1. 行情层：K 线、成交量、EMA 等指标。
2. 策略证据层：冻结策略生成的结构、标记和计划，只读。
3. 人工图形层：交易员画线、缺口、仓位工具与文字，可编辑并持久化。
4. 提醒层：价格线和本机收盘提醒，可编辑但不自动下单或外发消息。
5. 临时交互层：十字线、选中框、锚点和绘制预览，不保存。

### 右侧上下文栏

默认显示“策略匹配 / 自选标的”两个导航页签。策略候选卡只保留选图需要的信息；当前标的的 Entry、SL1、MM、风险和收益集中放入决策卡。对象树列出策略证据、指标、人工图形和提醒，支持逐项显隐、锁定、编辑和删除。

持仓与已清仓入口复用相同面板位置，改为展示实际买点、综合成本和已保存止盈止损。图表内核、人工对象和操作习惯保持一致。

## 弹窗和关键交互

### 对象属性

单击选中对象，显示浮动快捷条；拖动图形移动整体，拖动圆形关键端点调整结构；双击或对象树“管理”打开完整属性。属性入口统一为“样式、坐标、可见性”三页，但样式内容必须由工具定义：斐波那契管理级别与标签，仓位工具管理利润／止损区，上下箭头管理大小与透明度，矩形管理边框与背景，多段折线管理节点。颜色使用色板选择，线宽和线型可直接设置。修改后立即保存到对应标的图表草稿。

### 提醒

闹钟加号打开创建提醒：选择标的或指标、条件、阈值、频率和名称。第一阶段只在新 K 线收盘后判断，不补发历史事件，不外发消息。创建后提醒同时出现在图上的价格线和对象树。

### 回放

回放进入独立状态：第一次点击先打开“选择日期”，日线时间固定为 00:00，可在月历、日期输入或“第一个可用日期”中确定起点。确定后截断未来 K 线，显示虚线边界和“回放”水印；底部控制条按 TV 顺序提供日期、播放/暂停、逐根前进、0.1x–10x 速度、日线更新周期、更新至最后一根和退出。播放/暂停同时支持 `Shift +`。回放期间策略证据只显示当时已经成立的内容；人工图形按创建K线决定是否可见。退出前询问是否保存回放位置，离开后恢复当前行情与进入回放前的视口。

### 快照

相机在用户点击后生成当前缩放范围的完整图表 PNG，优先直接复制到系统剪贴板并给出成功提示；浏览器未开放图片剪贴板时才进入预览保存。快照包含行情、策略证据和人工图形，不包含个人侧栏，生成过程不上传数据。

### 显隐与移除

左下眼睛菜单可分别隐藏图形、指标、策略证据或全部内容，隐藏不删除。垃圾桶菜单只能移除人工图形和指标；冻结策略证据始终不出现在删除清单中。

## 数据持久化与身份

图表状态继续由 `workbench/store.py` 写入本机运行仓。状态以“证券代码 + 行情来源 + 复权口径”为行情身份，同时需要增加证券级人工对象身份：交易员在同一证券上的主观画线默认可跨来源显示，但必须记录创建来源与复权坐标；切换来源或复权后若价格坐标无法可靠换算，则显示为“待核对”，不静默移动。

建议保存结构：

- 证券视图：当前周期、可见根数、横向偏移、纵向比例、右侧面板状态。
- 指标：类型、参数、颜色、可见性、顺序。
- 人工对象：类型、锚点时间和价格、样式、锁定、可见性、创建来源与复权口径。
- 提醒：条件、阈值、周期、最后判断 K 线和启用状态。

数据库结构若需变化，只能由 `workbench/store.py` 升级；升级只增加表或字段，不删除现有图形和用户记录。

## 技术落地

保留 Python 的行情、策略、计划、提醒状态机和 Store。图表展示改为本机嵌入式 Web 视图：K 线和高频交互由 Canvas/WebGL 图表层完成，工具栏、对象树和弹窗由 HTML/CSS/SVG 完成，Python 与页面通过受控桥接交换 JSON。

当前 Tk Canvas 版本仍可作为回退入口，但不再继续堆叠字符图标或位图叠加功能。它无法稳定复刻价格轴拖动、对象锚点、复杂弹窗、高清缩放和跨平台一致视觉。

推荐目录边界：

- `gui/chart_shell.py`：创建本机 WebView、窗口生命周期和 Python 桥接。
- `gui/chart_bridge.py`：读取行情、策略证据、持久化图形、管理提醒。
- `gui/chart_web/`：前端源码与发布后的本机静态资源。
- `workbench/chart_workspace.py`：继续负责文档校验、分钟聚合、撤销语义和提醒状态机。
- `workbench/store.py`：唯一数据库升级和保存入口。

前端图表库仅负责基础 K 线与坐标变换；斐波那契、仓位工具、路径、平行通道和 GAP 证据均由 Aplus 自己的可测试图元实现，避免依赖第三方付费绘图组件。

## GAP H2 视觉契约

GAP 区域、Gap Floor、Gap 标签与引线统一使用灰白色 `#CBD5E1`。区域保持 1.2px 虚线、透明度约 0.6、无填充；Floor 为同色 1px 实线、透明度约 0.5；Gap 标签使用深色底与灰白引线，不使用蓝字白底框。缺口几何与策略计算不变。此前文档把恢复样式写成蓝色空框是错误口径，以用户明确要求的中性色标注为准。

BO、H1、H2、MM low 和 Gap Floor 的文字及引线继续使用灰白中性色，避免与上涨／下跌 K 线混淆。Entry、SL1、风险收益卡、H2 真实触发 K、失效与过期语义不因本次视觉恢复而变化。

## 策略图表标注（跨策略评估方案，2026-10-28）

**状态：建议评估中，尚未改造生产绘图。** 本节是实际行情主图的跨策略标注子规范，适用于候选、关注、研究和交易上下文；MTR 与 GAP H2 仅为映射和验收案例，不是两套独立标准。沿用上文五层边界。研究教学用的[策略全周期总图](策略全周期总图规范.md)仍按六阶段表达；实际 K 线不强制增加六段标题或画出全部假设分支。主图只显示有证据的事件，详情区说明当前状态及已知失效原因。

业务约束仍以[修改约束 A01—A11](修改约束.md)为准。本次不调整策略信号、评分、价位、tick、回测成交口径或数据，不写观察、计划或账本。以下“应／推荐”描述目标设计，不表示 main 已实现；对其他策略只复用排版规则，保留各自语义与符号契约。

### 统一术语词典与语义角色

统一短词、释义位置和角色；不要求同名词在所有策略里代表同一种算法。图例始终绑定策略／版本，不能只凭 `H1`／`H2` 字符串猜字段或改名。主图保留 PA 常用短词，中文释义在紧凑图例和详情中提供；不在每个节点堆砌双语长句、阶段编号和评分。

| 词／角色 | 统一表达建议 | 语义边界 |
|---|---|---|
| BO | 突破结构点；指向该策略输出的突破 K 及价格 | 是否确认、突破哪条边界由策略决定；BO 不自动表示挂单触发或买入 |
| H1／H2 | 保留策略原术语；图例说明“高一／高二尝试”或“结构高点”等 | PA 的高一／高二尝试不等于所有策略中的第一个／第二个高点；MTR H1 是反弹结构高点，当前 H2 为空；GAP H2 的 H1 节点及 H2 触发按其专用适配器，不能凭同名合并 |
| leg | 价格运动腿；必要时标 `Leg↑1`／`Leg↓1` | 必须有同一结构内的起点日期／价、终点日期／价和方向；序号只在该结构内有效，不从可见窗口随意找两极值拼腿 |
| Gap | 缺口区域；短标签＋中性无填充虚线框 | 仅显示原策略给定的上下界与形成区间；不把普通波动区画成缺口 |
| Gap Floor | 缺口下界结构参考；中性细实线 | 不是天然 SL；正式止损是否在其下方、相差几档依实际策略／计划，绘图层不推导 |
| TL／趋势线 | `TL` 可作为策略原生节点名；几何趋势线图例写 `趋势线` | MTR 的 TL 是测试低点，不是 trendline；几何趋势线必须保留真实端点，未输出就不补画 |
| MM low／MM high | 丈量参考锚点，指向具体 K 及原价 | 不是目标价，也不是成交价；只在该策略实际输出相应锚点时显示 |
| MM 测量段 | 用中性细线连接量距两端，必要时写 `MM 基准` | 连接的是算法提供的测量锚点；不可由图上距离反算策略参数，不把测量线当趋势线 |
| MM 目标 | 水平点划线，写 `MM参考 价格`；若确是正式目标则写 `TP1（MM）价格` | MM 公式／投影基准由策略决定；MTR 原生 2R 不借名 MM，GAP 的 MM 参考不自动等于当前正式 2R 目标 |
| S／signal | 已确认信号 K；MTR 推荐短词 `S`，其他策略保留已有专属信号词 | signal 不等于 Entry 计划，不等于触发或 fill；内部形成阶段写“未确认”，不发布成 S |
| Entry 提醒／计划 | `Entry 价格`，详情列计划日期及状态 | 价格提醒、次日计划、挂单触发和成交是独立状态；仅碰到价位线不能由绘图器认定成交 |
| SL／SL1／TP1／TP2 | 角色＋价格；参考止损加 `参考`，多目标保留编号 | SL1 是否正式止损以实际计划为准；不能跨策略统一重算 SL，或把参考 MM 改成已执行 TP |
| Trig／fill／exit | 触发、模拟成交、人工真实成交、退出独立事件 | `trigger != fill`；每个事件有日期／价／来源，模拟与实盘始终有显式类型文字 |

策略详情记录角色与原字段映射、机会身份、来源／复权／周期、规则版本、原始日期和确认可用时刻。未确认、失效、过期、未成交及证据不足分别写明，不用灰色一概表示失败。当前规则、PA 解释、研究候选在详情和导出图例显式区分；不因采用新样式就宣称研究候选已成为现行规则。

### 通用几何与分层规则

| 图元 | 锚点、几何与线型 | 范围／状态 |
|---|---|---|
| 节点与引线 | K 线水平中心＋原输出价格；中性细实线引线，线端留空隙 | 显示偏移以像素计，不改日期和价；节点与确认时刻分别表达 |
| leg | 起止两锚点间的中性 1px 线段，小方向箭头；短标签在段侧 | 未确认腿在详情注明 `形成中`，用疏虚线；完整腿才用实线，不向两端自动延伸 |
| 趋势线 | 原始两点／原序列；中性 1px，默认虚线，与 leg 的有限实线段区分 | 仅按原输出／显式投影范围延伸；人工趋势线留在人工图形层，不能冒充策略证据 |
| 缺口 | `#CBD5E1`、1.2px 虚线、无填充、约 0.6 透明度；Gap 指区域中心 | 保留形成日期和上下界；回补／结束只依据实际记录，不按遮挡需要缩改框 |
| Floor | 同色 1px 实线、约 0.5 透明度 | 起于对应缺口，延伸至策略已知范围／视口右端；未知存续注明待核对 |
| MM 测量 | 中性 0.8–1px 点线、两端短刻度；文字 `MM 基准` | 只连测量两端；投影段如有原输出，用中性虚线并写 `投影`，不与正式 TP 混同 |
| 计划价／目标 | 角色色＋文字＋专属线型，具体参数见下表 | 有限归属区间；不修改计划值，不让色彩成为唯一编码 |

锚点缺失或无法映射时省略相关图元并提示原因；绝不夹到首尾 K、不为美观补点。结构线、计划线与事件标记不同层显示；同一根 K 上出现多个角色时保留独立对象并避让文字。下面的参数、选中／历史与导出规则是跨策略共用规则，MTR 的圆／菱形方案只是角色区分示例，不覆盖 A11 保护的其他策略专属符号。

### 信息层级与多历史信号

跨策略优先级统一为：价格与当前选中结构 → 信号和计划 → 历史信号 → 中文说明。符号必须区分结构、信号、触发、成交；各策略保留专属形状契约，不统一成星号或菱形。中文图例与类型文字随图导出。

**当前选中机会与历史显示：**

1. 选择以候选／关注上下文的策略、版本、来源、周期及 `setup_date/asof` 定位，优先复用现有身份；不以最后一根可见 K 或窗口中最后信号替换它。无精确匹配时明确“原信号待核对”，不自动选另一笔冒充。
2. 默认只展开该机会的原生结构节点（MTR 本案为 H0／L1／H1／TL／S）、归属计划线和详情。其他历史信号保留该策略专属符号，建议 6px、符号透明度约 0.45（MTR 本案为空心菱形），无结构长标签、无风险线；“历史信号”开关只控制显示，不删除数据。选中操作改变查看对象，不改选股或账本状态。
3. 日期／索引须先映射到**原计算序列**再按日期投影到可见窗口。不能把全量 `_idx` 当成 tail/reset 后的局部索引，或把越界日期夹到首尾 K；周／月图按既有日期归属规则投影，不重写日线节点。
4. 缩放不重新找极值、不更换选中机会。节点在视口外时省略该点并在详情提示，不把标签拖到图边伪装为可见节点。历史与当前不能混用不同计算前缀的结构列；来源不足时保留归档价位并明确结构待核对。
5. 回放严格遵守当时可见边界；信号 K 日期与确认可用时刻分别保存／使用。字段不足以证明当时已确认时，不将事后算出的完整结构提前显示；这是后续实现的验收前提，不表示本 PR 已修复回放。

### 线色、线型与区间（目标参数）

以下以 CSS 逻辑像素为基准。结构注释统一中性灰白；价位可按角色着色，文字、线型必须独立可辨。行情沿用既有主题，不能给 K 线换色来迁就标注。

| 角色 | 目标颜色／线型 | 范围与文字 |
|---|---|---|
| 结构标签、锚点、引线 | `#CBD5E1`；引线 0.9–1px 实线 | 引线只连接标签与真实节点，不连成未经输出的“趋势证明线” |
| Entry | `#089981` 青绿；1px，点线 `[2,4]` | `Entry 价格`；仅代表计划价，不能以此标成交 |
| SL | `#F23645` 红；1px，虚线 `[6,4]` | `SL 价格`；不能把 GAP 的 SL1 改名搬入 MTR |
| TP1 | `#D6B86A` 沙金；1px，点划线 `[8,3,2,3]` | `TP1 价格`；不与橙色 EMA 混称，必须保留线型与标签 |
| 结构参考价／研究候选价 | `#9BA7B4`；0.8px，疏点线 `[1,5]` | 明写 `参考` 或 `研究候选`；只有该策略实际提供时才画 |

价位线从选中机会的已知计划生效日期起，画到已知失效／结束时点与当前视口右端中较早者，禁止从全图最左边穿过无关历史。若没有计划有效期证据，只画从选中信号到当前视口右端的**显示参考区间**，详情标“有效期未核验”，不得暗示一直有效或补造终止日期。起点或价位缺失则省略该线并解释；不把结构低点当 Entry。离开视口的价位可在详情列出，不为强塞全部目标而过度压扁 K 线。

价位标签贴在线的右端并内收 8px，写角色加按品种精度格式化的价格；同价位只合并几何线，保留所有角色文字与归属。SL 与 TP 接近时标签可上下错开并用短接线指回原价，**价格线本身不移动**。计划、已知事件与研究候选依靠文字状态区分，不能把“所有虚线”解释为“未实现”；本节角色线型不套用全周期示意图的路径虚实含义。

### 标签避让、留白与深色对比

- 背景沿用 TV 主图 `#0B0B0B`、网格 `#1F1F1F`；标签底 `#171717`（90–94% 不透明）、内边距横 4px／纵 2px，无亮色大边框。常态短标签 11–12px，行高 16px，常规字重；图例 11px，选中只提高轮廓清晰度。
- 标签锚点是日期＋原价，偏移是屏幕像素。优先尝试右上、左上、右下、左下的 16–32px 偏移，优选斜引线，总长建议 12–48px，上限 64px；线端距实体／影线 4–6px。不要再用价格乘 0.90／1.10 决定文字位置，不画貌似加长影线的竖引线。
- 每次渲染后测量真实文字框，先检查绘图区四边（内边距 ≥8px），再避让 K 线／影线、价位标签、其他结构文字、决策卡、浮条和轴区；不能只限制标签中心。候选位置打分后选最少遮挡者，禁止重绘累加偏移。
- 当前重置视图已有约 12 根 K 宽右侧空间，应保留。纵向自动范围建议上／下各留 8–12% 价格空间并校验实际文字框，空间不足时先换标签方向，再移出说明到详情；手工缩放不得被强制重置。
- 文字与实际合成背景对比度 ≥4.5:1，关键符号／线与背景 ≥3:1；历史文字不沿用符号低透明度。灰度查看仍可由 `S / Trig / 模拟买 / 实盘买`、空实心与不同线型辨别，不靠红绿猜含义。
- 缩放／平移／改变窗口尺寸时重排标签、不改数据坐标；短标签保持可读字号，不随 K 线放大成大字。密集时先隐藏历史标签，再将次要说明移入详情，不遮住当前 S 或隐藏缺失提示。

### 屏幕、静态图与导出

常用桌面 1920×1080、2560×1440；窄窗口 960×640，并补测 640×480 的独立图区域／多图格子。Windows 100%／150%／200% 显示缩放各核对一次：按逻辑像素排版，Canvas backing store 随 DPR 增大，不能重复放大标签。

快照只包含当前视口、行情、策略证据、用户显式可见图形及紧凑图例；补充策略／版本／周期、来源／复权、选中信号日期、规则状态。研究图须写“研究／模拟”，不得泄露个人侧栏。PNG 以当前逻辑布局的 1×、2× 导出，几何和锚点一致、文字清晰无裁切；Matplotlib 导出按最终 DPI 重测框。导出缺少悬停功能，必须保留中文释义与“未确认／待核对”提示，不能仅交一张无身份的大白星图。

### 现行语义核对：先修清楚来源，再谈好看

- `core/strategies/mtr_structural_v35.py:match_mtr_pattern()` 当前返回 `H0 / L1 / H1 / TL`；SETUP_READY 中 `H2=None`，SETUP_FORMING 的 TL 是潜在测试点。不存在可凭外观补齐的已确认 H2。
- `core/strategies/mtr_strategy.py:calculate_signals()` 保留多笔 `signal_mtr=True`；将结构的 `mtr_{H0,L1,H1,TL}_idx/price` 复制到信号行。正式信号来自 TL 后找到的合格光头阳线，`SETUP_READY` 本身不等于有正式信号；检测位置也不等于信号 K。
- 当前 `annotate_chart()` 只找传入序列的最后一个 True 信号，用信号前全窗口最低点和其后最高点近似“Climax／First Leg”，并把信号 K 的 low 标为 `SIGNAL (HL)`；低点与信号重合时甚至以低点乘 1.05 生成 leg1 绘图位置。这些是现有绘图近似，**不得作为已核验的 L1／H1／TL**。
- `gui/chart_evidence.py:strategy_evidence()` 先按 `setup_date/asof` 截断历史，再调用原策略标注；`marker_specs()` 却会保留该前缀内全部历史信号。因此“多枚星＋末笔详细文字”有代码依据，不是只把星缩小就能解决。
- 当前 MTR 原生 Entry 优先取信号 K high，SL 实现为 `min(L1, TL) - 0.01`，TP1 为 Entry + 2R（另有 TP2=3R）。此处 0.01 是现行代码固定值，不推广为所有品种 tick；本次不改价、不额外加一档，也不把 TP2 或结构点默认显示成新的交易指令。截图的 14.99／26.36 仅是可见文字，未用行情重算验证。
- GAP H2 的 WebView 专用路径在 `prototype-interactions.js:drawStrategyEvidence()`，使用中性结构标注、Entry `#089981`、SL1 `#F23645`；Matplotlib 的 `h2_chart.py`／`theme.py` 有中性价位样式。不能声称两条路径已经完全同色。新的 GAP 计划还区分正式 SL／2R 与 SL1／MM 参考；参照截图的 SL1 不等于 MTR 的 SL。

### MTR 的短标签与符号映射示例

优先顺序为：**价格与当前选中结构 → 信号和计划 → 历史信号 → 中文说明**。不让大符号、长段文字或底部卡片遮住 K 线。

| 主图短标签 | 中文图例／语义 | 数据锚点与符号 |
|---|---|---|
| H0 | 下跌背景起点 | 同一信号行的 `mtr_H0_idx/price`，中性空心圆 6px |
| L1 | 下跌极值低点（原图称 Sell Climax） | `mtr_L1_idx/price`，中性空心圆 6px；“抛售高潮”作为解释，不由绘图器重新推算 |
| H1 | 第一轮反弹高点（原图称 First Leg） | `mtr_H1_idx/price`，中性空心圆 6px；与 GAP H2 的 H1 含义分别在各策略图例说明 |
| TL | 回调测试低点 | `mtr_TL_idx/price`，中性空心圆 6px；不得用信号 K low 代替，不强制改名 HL |
| S | 已确认信号 K | `signal_mtr=True` 所在日期，中性空心菱形 8px；可在 low 下方留 6px 间距，逻辑锚点仍是原 K 线 low |
| Trig | 挂单触发事件 | 只有明确触发记录才画空心上三角 10px，指向事件日期／价格；不是 S 的同义词 |
| 模拟买／实盘买 | 模拟成交／人工确认真实成交 | 有相应来源记录才画实心上三角 10px，卖出用实心下三角；类型文字始终显示，不能仅靠填充或颜色区分模拟与真实 |

结构点、S、触发、成交均须保留独立身份；同一根 K 重合时只移动标签，不合并事件。选中 S 可加 12px 外轮廓，禁止恢复大白星或使用涨跌色给结构“打分”。没有信号时不画 S；缺失、NaN、尚未确认或无对应原始日期的节点不画，并在详情列出“TL 未确认／H0 不在窗口／结构待核对”等准确原因。不能因为有 `mtr_stage` 就补造整套结构。

图例可固定为一行 `○ 结构点  ◇ S 信号  △ Trig 触发  ▲ 成交（见类型）`，中文全称在可展开详情；静态导出附紧凑释义，避免依赖悬停。常态主图不出现长英文加中文双行解释。

### 与 GAP H2 的一致性映射

| 可统一的表达 | GAP H2 参考 | MTR 对应与边界 |
|---|---|---|
| 短标签＋图例 | BO、H1、Gap、Gap Floor、MM low | H0、L1、H1、TL、S；H1 同名不代表同一算法 |
| 精确结构锚点 | BO／H1 对应 K，Gap 指向区域中心 | 读取同一 MTR 信号行的原结构节点；不使用全窗口极值近似 |
