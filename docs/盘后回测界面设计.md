# 盘后回测：交易员工作台布局

在 GAP H2 提速版本上重设计实际 Windows 桌面入口，不替换冻结策略或 Web 回测。按本机 `ui-ux-pro-max` skill 的流程，采用其 Data-Dense Dashboard、深色可读性、键盘与空状态建议；保留 Aplus 石墨配色和 A 股红涨绿跌约定，不沿用生成器中面向营销网站的横向浏览布局。

## 页面与操作

- 顶部：盘后回测标题、历史结果与「数据与成交口径」。研究条件独立成一条控制栏，开始回测是唯一主操作，停止为次操作。
- 范围：默认全选当前已存股票的主板／创业板／科创板／北交所，复用更新行情的 BOARDS、board_of 和范围文案。允许多选，按钮不追加「已存行情」；零板块阻止开始。关注名单保留在同一菜单，不受板块勾选限制。不下载新行情，不把不存在的股票补造进统计。
- 结果：五张指标卡分别给出机会数、触发率、已结束胜率、扣费后平均净 R、已成交初始风险中位数，标题与统计分母分层。左侧约 76% 给机会清单；右侧给 Top 盈利、Top 亏损及净 R 分布。高度不足时盈亏样本用两标签切换，其他情况下同时展示。样本仍各最多五笔，并可滚动和复盘。
- 状态：未运行、回放中、没有机会、筛选为空、停止／部分完成、读取失败各有明确提示，不展示演示收益。停止或部分回执保留可见标记；逐笔页也提示部分结果。
- 历史：选择历史结果后日期及已记录研究条件同步，旧回执没有板块信息时不补造历史范围。
- 复盘：收起研究控制与任务进度，把主要空间让给 K 线。图表按当前图区宽高重新绘制，不只缩小、不裁切原图，也不靠改变横纵价格关系拉伸填满。右侧约 300 像素（随大窗口字号适度增加）展示事件列表、当时／事后模式和当前事件说明。仍按所选事件截断行情，后续事件不会进入图表或计划计算。

## 设计约定

通用颜色、字体、间距、密度和状态规则统一维护在 [统一 UX 规范 V1](统一UX规范V1.md) 第 4～7 节。本页当前实现以正文 13、标题 24、指标 30 基础像素与表格行高 30 为起点；宽窗口字号适度增加，最高 1.6 倍。该缩放是当前页面实现，不作为其他页面必须照搬的规则。

正常文字使用高对比辅助色，盈亏不单靠颜色表达；主次按钮保留悬停和键盘焦点边框。Enter／双击打开所选机会，↑↓切换机会、←→切换事件，Esc 返回并保留原清单选择。复盘原生分辨率图缓存最多八张，窗口变化后重新绘图，避免固定图片在大容器居中产生留白。

## 验收

完整代码回归与冻结校验；额外覆盖四板块筛选、最新快照去重、零板块阻止、后台拒绝越界标的并记回执、宽／高图区原生尺寸、实际 Windows 复盘与返回定位、小窗口盈亏标签、历史日期同步。真实行情窗口截图只在独立验收数据仓生成，验证 1280×760、1600×1000、2560×1440 的结果页与复盘页，九张正式业务表行数不变。

可复验：`python -m tools.preview_afterhours_layout --home <独立验收数据仓> --output <截图目录>`。只接受已有工程验收标记的目录，不打开日常数据仓。视觉截图与代码检查属于工程验收，长期交易员使用尚待实际验收。
