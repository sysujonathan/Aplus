# 启动器编码修复

`启动A.vbs` 的恢复提示曾加入无 BOM 的 UTF-8 中文字符串。Windows Script Host 在无 Unicode BOM 时依赖系统代码页，因而可能报 800A0401。改存 GBK 只适用于相应代码页，不能作为跨机器修复。

PR80 已将主线改为纯 ASCII 脚本，通过十六进制码点与 `ChrW` 在运行时生成中文恢复提示。本 PR 同步并保留这套实现，替代此前的英文提示方案。没有 BOM、中文或其他非 ASCII 文件字节；cp936、cp1252 和 UTF-8 解码后的脚本相同，Git 仍可逐行审查。中文路径由 WScript 的 Unicode 路径接口读取，不要求用户改安装目录。

保留原有注册表运行目录、更新事务恢复、解释器指针、退出码与隐藏启动流程。只改变提示文本和编码约束；不运行实际升级、不修改行情或交易记录。

回归要求：启动器严格按 ASCII 解码；恢复入口、解释器指针及启动参数仍存在；更新事务与桌面布局专项通过。代码测试与 Windows 宿主实际执行分别记录在独立验收文档中。
