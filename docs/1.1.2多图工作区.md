# 1.1.2 多图盘前工作区

## 日常使用

- 中间默认显示 `2×2` 四格 K 线；信号日右侧可切换 `2×3` 六格或 `3×3` 九格。
- 蓝色标题条代表当前活动图。点击任意图格即可把它设为活动图。
- 候选列表使用 `↑`、`↓` 逐股移动，保留原来的键盘习惯。同一页内只切换活动图；移动到另一页的股票时，自动显示该股票所在的一整组。
- 候选列表使用 `←`、`→`，或点击信号日右侧的左右按钮，按四只、六只或九只整组翻页。中间页码显示当前图组在候选中的位置。
- 每个图格右上角都有独立的 `TV ↗`，只打开该格股票的 TradingView 页面。
- 单击关注列表股票，会替换当前蓝色活动图；按住关注股票拖到某一格，则只替换落点图格。翻页、切换策略、日期或布局后恢复对应候选组，不修改关注记录和原始扫描结果。

## 采用的交互原则

本地界面借鉴 TradingView 多图布局的成熟做法：布局统一切换、一个活动图接收标的切换、每格仍保持独立标的。A 的用途是并排审核不同股票，因此不强制把所有图格同步成同一只股票；日线/周线仍由盘前工具栏统一控制。

首次打开一组图时，K 线会按格逐个生成，避免界面长时间没有反馈。已生成图在本次运行中缓存，来回翻页时直接复用；缓存只在内存，不写数据库。

## 不变的边界

- 原策略文件、策略参数和信号判定不变。
- 行情快照、观察记录、关注记录和交易计划的数据结构不变。
- 拖拽只改变当前屏幕图格，不删除候选、不删除关注、不写入人工计划。
- TradingView 仍由交易员主动打开，本工具不自动下单。

## 验收口径

1. 启动后默认四格；切换六格、九格时图格数量和排列正确。
2. 上下方向键逐股移动，左右方向键按组移动；工具栏左右按钮行为相同。
3. 活动图有蓝色标题条；点击其他图格后活动状态唯一转移。
4. 每格 `TV ↗` 打开本格代码，不受其他图格影响。
5. 关注列表单击替换活动格；拖入第二、第三等任意图格时只替换目标格。
6. 策略、日期、周期或候选结果刷新后，多图组与左侧候选保持一致。
