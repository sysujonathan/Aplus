# Gap Pinbar、AWIL 与 Structural Gap 快速拒绝验证报告（2026-10-25）

## 结论与使用影响

本轮三个策略均为 **GO：可以提交默认 OFF 的安全灰度研发能力，但不批准生产启用**。

三个冻结策略、正式交易参数、机会身份、GAP H2、行情门禁和数据库结构均未修改。不开环境变量时 Service 不构造新增控制器，日常扫描保持原路径。三策略虽然在一个 PR 交付，但各自拥有独立模式、人工授权、缓存身份和熔断；生产启用仍须逐策略审批。

## 必要条件证明

### Gap Pinbar

冻结原版只在末行同时满足 Pinbar 下影占比、收盘位置、当日首次刺破 EMA20 以及收盘站回 EMA20 时，才可能把 `signal_gap_pinbar` 置为真。门禁只检查其中四个低成本末根必要条件；历史突破、首次刺破计数、缺口存活、目标是否已到和去重仍交给原版。

### AWIL

末行 `signal_awil` 必经 H2、整组最低价始终高于 EMA20、阳线且收在顶部 2%。H2 当前确认本身要求最高价突破前高。因此末根不是强阳收顶、没有突破前高或最低价不在 EMA20 上方时，正式最新信号必为假。历史四阶段状态机、回调组和去重仍交给原版。

### Structural Gap

末行 `signal_struct_gap_confirm` 必须满足低点停止下移、最高价突破前高、阳线且收盘高于前收盘。历史突破、缺口防线、窗口、测距目标和去重仍交给原版。当前发布没有 `config/gap_optimized_rules.json`；若该动态规则文件出现，控制器不会猜测兼容性，而是直接回退原版。

## 真实行情与合法输入对拍

源仓通过 SQLite `mode=ro`、`query_only` 和快照事务读取，逐文件复核 SHA-256；没有联网，所有扫描写入独立临时 Store。源仓共有 5,165 只可读 BaoStock 最新日线，抽取 300 只并在五个交易日重新截断：`2025-10-09`、`2026-01-05`、`2026-04-08`、`2026-07-07`、`2026-09-30`。

| 策略 | 有效跨日比较 | 安全拒绝 / 原版通过 | 当日正式信号 | payload/异常差异 | 300 份合法生成反例 |
|---|---:|---:|---:|---:|---:|
| Gap Pinbar | 1,493 | 1,441 / 52 | 0 | 0 | 0 |
| AWIL | 1,493 | 1,469 / 24 | 0 | 0 | 0 |
| Structural Gap | 1,493 | 920 / 573 | 2 | 0 | 0 |

固定横截面中 Gap Pinbar 和 AWIL 没有正式信号，不能据此宣称安全。为补齐这一侧，另在 1,200 只真实股票的历史信号行上逐个按信号日截断并重新生成正式 payload：

| 策略 | 可复现正式历史信号 | 不满足门禁的正式信号 | 完整 payload 差异 |
|---|---:|---:|---:|
| Gap Pinbar | 38 | 0 | 0 |
| AWIL | 52 | 0 | 0 |
| Structural Gap | 814 | 0 | 0 |

完整 payload 覆盖 `asof`、`setup_date`、Entry、SL、TP、评分、评级和风险提示；Service 对拍另覆盖 observation 身份。测试还覆盖文本布尔、污染 ATR、无穷 EMA、陈旧收盘位置、OHLCV 改写、未知运行环境、旧授权、原版异常、差异熔断、缓存隔离，以及 CANARY/ACCELERATED 在 0、1 和中间比例的确定性分流。

### 周线覆盖边界

Gap Pinbar 与 Structural Gap 的周线路径使用同一正式末行语义。代码测试把 760 根合法日线聚合为超过 125 根周线，对不同长度前缀执行原版/SHADOW 对拍，零差异、零熔断。

当前真实源仓每只最多约 486 根日线，聚合后不足正式扫描要求的 125 根周线，因此本轮没有真实周线正式信号样本。周线生产启用必须等待长期仓 SHADOW；本报告不把合法生成周线冒充真实周线证据。

## 性能

### 单策略 detector 模型

同一 1,493 次真实日线前缀逐样本计时，模型把门禁成本与“门禁通过后仍执行原版”的实际成本合并，不与其他优化百分比相加：

| 策略 | 原版累计 | 门禁＋必要原版 | 局部减少 |
|---|---:|---:|---:|
| Gap Pinbar | 14.304 s | 3.010 s | 78.96% |
| AWIL | 12.901 s | 2.628 s | 79.63% |
| Structural Gap | 13.749 s | 7.679 s | 44.15% |

这是 detector 局部模型，不是全市场或一键盘前墙钟。

### 六策略真实短历史 Service

60 只真实 BaoStock 短历史、六个策略、隔离 Store、冷缓存、三轮交错。计时包含文件读取和 SHA、公共指标、六策略、审计事件、每股耐久事务和终态回执，不含网络行情更新或正式全市场质量预审。

最终同池逐策略、三策略组合和五套加速组合数据以验证工具输出为准。所有模式、所有轮次必须共享同一个 `business_digest`，否则工具失败，不取第一轮冒充一致。

三策略组合共享一次可信输入复核，避免同一 OHLCV 重复校验三遍。独立启用时 Structural Gap 在 60 股墙钟中收益可能被输入复核与机器波动抵消；它的局部 detector 仍有约 44% 可节省时间，其对组合的真实边际收益在下表和原始输出单独报告，不把局部百分比当端到端收益。

同一 300 股母样本中固定抽取 60 股，逐模式三轮交错的最新一组结果：

| 模式 | 冷扫描中位数 | 相对 OFF | 业务结果 |
|---|---:|---:|---|
| 全部 OFF | 9.325 s | 基线 | 一致 |
| 仅 Gap Pinbar 加速 | 8.923 s | -4.31% | 一致 |
| 仅 AWIL 加速 | 8.978 s | -3.72% | 一致 |
| 仅 Structural Gap 加速 | 8.973 s | -3.77% | 一致 |
| 仅新增三策略全部加速 | 8.371 s | -10.23% | 一致 |
| MTR、3K 与新增三策略五套加速 | 6.654 s | -28.64% | 一致 |

前一组相同母样本、相同三轮交错得到 9.272→7.949 秒（新增三策略 -14.27%）和 9.272→5.697 秒（五套 -38.56%）。另一个 60 股抽法得到五套约 -42.88%。Windows 单机短任务存在明显调度噪声，因此不选择最好一轮宣传，也不把百分比相加：保守结论是新增三策略在该短历史样本提供约 **10%—14%** 的六策略墙钟改善，五套隔离全开约 **29%—39%**；它不是全市场、长历史或一键盘前承诺。

OFF / 新增三策略 / 五套加速每轮 `business_digest` 均相同，错误均为 0。最新同池 OFF、三策略、五套分别写入 423、603、723 条事件，数据库约 448、584、656 KiB；增加的是灰度判断和可追溯证据，没有减少每股事务或审计。三策略生产 OFF 时没有上述额外事件和空间成本。

## GO / NO-GO 与剩余风险

| 策略 | 研发结论 | 生产启用前仍需完成 |
|---|---|---|
| Gap Pinbar | GO，默认 OFF 灰度 | 全可扫池日线 SHADOW；长期仓周线 SHADOW；TickFlow 同范围 |
| AWIL | GO，默认 OFF 灰度 | 全可扫池日线 SHADOW；TickFlow 同范围 |
| Structural Gap | GO，默认 OFF 灰度 | 全可扫池日线 SHADOW；长期仓周线 SHADOW；确认目标机无动态规则文件 |

真实样本未观察到原版业务异常。未抽样 ACCELERATED 样本仍存在“原版在合法输入上发生此前未见业务异常”的理论剩余风险，因此必须先 SHADOW，再逐策略小比例 CANARY；任何可信差异立即熔断，不批准直接全开。
