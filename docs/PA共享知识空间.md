# PA 共享知识空间

## 连接 Google 账号

公共案例只有一个权威位置：[PA知识库](https://drive.google.com/drive/folders/18qe7MkUJTEndpAM9J1H_Y5-mjbh7l5aX)。文件夹 ID 固定在客户端，不接受页面传入替代目录。

2026-11-04 用户明确将目标改为截图中的“PA知识库”，已按精确名称及 ID 核实；旧目录不再是活动知识源，不自动搬迁或删除其资料。新目录已读取权限，`shared=false`、只有 owner。连接器与 Aplus 桌面授权相互独立；本机单账号桌面授权及三组测试案例的真实 Google 验收现已通过，不代表团队成员已能访问。

安装后打开 PA 成长空间，点击左下“连接 Google 账号”，由本人在系统浏览器登录并同意授权。完成后返回成长空间，读取指定 PA知识库。普通使用者不需要创建 Google Cloud 项目、下载或选择 OAuth JSON。

正常重启会复用本机当前 Windows 用户安全保存的登录；授权失效后可点“重新授权”，更换成员可点“切换账号”。“断开连接”清除本机活动凭证，不删除案例。Google 应用当前仍在测试中，只有负责人批准的测试账号可授权；其他账号可能显示 403 access_denied。这是外部发布状态限制，不等于正式公众登录已开放。

团队负责人另需把该文件夹共享给成员为“编辑者”，并在应用测试期间将其加入测试用户。不要开启公开链接。多账号 3+2/两个客户端一致性及个人隔离仍按用户安排后续补验；本机单账号通过不代表团队整体上线。

本版请求 `https://www.googleapis.com/auth/drive`，属于完整 Drive 授权，并非 Google 提供的单文件夹权限。这样才能读取其他团队成员在既定目录创建的文件；客户端的业务读写严格限制在指定目录。若不能接受此授权范围，应暂停真实连接，由负责人另行确定授权方案，不能用本地假同步替代。

该权限允许查看、下载和管理整个云盘文件；凭证若被滥用，影响可能超出 PA 文件夹。客户端固定目录是应用约束，不是 Google 的服务端单目录限制。较小的 `drive.file` 只覆盖应用创建或用户通过 Picker/应用逐项授予的文件，不能直接替换本版“发现其他成员在固定目录提交的全部案例”；需要另行调整选文件和授权流程，本批不切换后端或暗中扩大方案。`drive.readonly` 又不能提交案例，且仍可读整个云盘。只在可信本机授权；不再使用时可在 Google 账号中撤销 Aplus 授权。

授权采用 Google 支持的桌面 PKCE 与回环回调，系统浏览器处理登录；回调校验随机 state。凭证用 Windows DPAPI 加密，位于当前 Windows 用户的 `%LOCALAPPDATA%/Aplus/PA-Google/<运行目录指纹>/session.dpapi`，不在运行库、ZIP 或共享目录内。不同运行目录使用独立活动登录，支持同一 Windows 用户下的两套隔离客户端，不会在刷新令牌时相互替换账号。断开连接删除本机活动凭证并清空页面缓存中的上一账号内容；不删除云端案例和个人学习记录。

### 发行资源与维护者边界

正式发行任务在既有 main 验收门禁通过后，从仓库 Actions 构建输入 `APLUS_GOOGLE_DESKTOP_OAUTH_JSON` 自动生成 `resources/google-desktop-oauth.json` 并打包；本机资源文件被 Git 忽略，不把客户端配置写进源码历史。正式应用从已安装程序资源目录定位，不依赖开发电脑路径或工作目录。它仅允许 Google Desktop 公共客户端的 `client_id`、`client_secret` 和可选项目标识；Google 将 Desktop 客户端视为不能保密的公共客户端，这里的 `client_secret` 是随客户端分发的协议参数，不能当作后端机密或用户身份凭据。用户 Access/Refresh Token、登录缓存、账号资料及 Service Account 私钥不得进入发行资源。

`tools/prepare_oauth_resource.py` 只接收 Desktop 公共配置并剔除导出元数据，不输出内容；缺失、损坏或混入用户/服务账号材料时停止，保留原有效资源。该构建输入已配置到本仓库，不需要最终用户处理。构建脚本及独立 PyInstaller spec 均验证配置；缺失、损坏、混入其他字段时停止构建。实际 payload 的 JSON、私钥头和用户缓存文件另做审计，既有文件清单及更新恢复门禁保持。安装资源损坏时明确报错，不恢复手动选择 JSON。授权等待最长十分钟，期间显示等待状态；取消或超时返回 PA 并提示重新点击连接，不要求刷新旧回调页。更新携带同一资源，个人登录仍保存在独立 Windows 用户目录。

源码开发或自动化测试可用 `APLUS_GOOGLE_DESKTOP_CLIENT` 指定独立桌面配置，或在 Python 测试中显式传入路径；冻结安装版忽略该环境变量并拒绝显式路径。该变量只用于源码运行；本机打包仍须先用 `tools/prepare_oauth_resource.py` 从构建输入生成固定资源文件，spec/build_installer 不读取这个开发变量。维护者继续负责在同一 Google 项目启用 Drive API、维护受众/测试用户及应用审核；普通用户不承担这些设置。内置公共配置不会缩小完整 Drive scope，也不能代替 Google 审核。

同一运行目录的多个窗口每次操作重新读取登录记录。短文件锁和版本比对阻止旧续期/迟到登录覆盖新账号，网络等待不持有凭证锁；一次业务调用绑定登录代次。页面每秒及恢复可见时检查本地账号/公共权限状态，切号、退出或明确撤权后清除旧个人内容、原图和迟到响应；提交同时核对用户看见的账号状态，防止旧页面文字误写新账号。这个检查不轮询 Google，不影响其他交易模块。

## 收录与提交

粘贴、拖拽、批量导入继续保存原始字节。未填术语可“存草稿”；“保存案例”至少选择一个 Brooks 英文术语。两种操作均先保存为本机私密草稿，保存后切回私密列表，避免以为截图丢失。

打开私密案例，在“提交到公共空间”核对原图数量、描述和术语后确认，才开始云端上传。公共内容包含原图（包括图中已有文字）、案例描述/关键词、术语、创建/更新时间和稳定贡献者身份。私人研究笔记、判断、学习记录、旧中文主题不会上传。历史草稿不自动发布。

同一案例的公共提交是不可变快照。本版不支持编辑或撤回公共记录；上传者在本机继续编辑不会覆盖公共原件。重复点击或上传中断后重试同一快照，沿用原提交身份；若快照已变，明确拒绝混用，另存案例后再提交。不同案例或相同品种不自动合并。

## Drive 文件组织与可靠性

所有文件都直接位于指定目录，使用 Drive 的继承权限，不另外创建平行知识库：

| 文件 | 内容 | 生效时机 |
| --- | --- | --- |
| `image-<Drive ID>` | 一张原始图片，正确 MIME，SHA-256 和字节数 | 上传成功并逐文件读取校验 |
| `cover-<Drive ID>` | 有界 JPEG 缩略图 | 只加速浏览，不能替代原图 |
| `case-<全局案例 UUID>.json` | v1 manifest，原图关联、标准术语、贡献者、时间、可选渐进设置 | 原图和封面全部验证后最后创建，作为唯一公开提交标记 |

客户端先向 Drive 预分配文件 ID，再经 Store 把发布保留记录写入现有 `meta`。重试使用同一组 ID；只有创建和核对，没有 PATCH 其他成员文件。最终 manifest 经读取核对才返回“公共案例已提交”。若云端已确认但列表刷新失败，分别反馈这两个结果。

未完成上传可能留下未被案例引用的原图，不进入案例检索和图谱；本版不自动删除它们。不要人工清空指定目录来解决问题。成员在 Google Drive 网页中仍拥有编辑者的实际能力；客户端的不可变协议不能阻止成员绕过 Aplus 手工改删云盘文件。共享成员应是受信团队。

刷新分页发现所有公共 manifest；已经校验且 Drive MD5 未变的记录复用缓存，云端内容被改动时明确拒绝覆盖。新增 manifest 检查固定父目录、贡献者与 Drive 所有者的 permissionId 一致、唯一案例 UUID、有效术语及渐进设置。整批通过才替换缓存；损坏目录保留上次有效快照并报错。当前有界加载上限为 20,000 例、目录 32 MiB，单例仍最多 100 张/128 MiB。拒绝超限不删除原记录。

公共目录缓存、访问确认和上传 ID 保留均按 Folder ID 命名隔离，内存缓存也核对 Folder ID；旧版无目录标记的缓存/访问确认及旧上传保留原样保留，不作为新目录成功访问或提交的证据。公共目录缓存存于 Store `meta`，原图/封面按需校验并缓存于 `<运行目录>/pa_growth/shared_cache/<Folder ID>/`。缓存是权威云端记录的副本，不能在离线时新增公共案例或修改公共原件。缩略图独立逐张加载，不等待网络后才显示文字结果，也不占用保存写入锁。离线可浏览已经缓存的图片；未下载图片明确失败。校验异常时只在新下载验证通过后替换可重建缓存。收到明确 401/403 访问拒绝或目录 404 时停用该账号公共缓存授权，需重新授权或恢复权限后刷新。单图片 404 先核验目录：目录仍可访问（包括只读）时仅报该图片不可用；目录亦拒绝访问时才停用全库缓存。

上述撤权统一覆盖刷新、原图/缩略图和提交；同一运行目录其他窗口也会停用缓存。并发的旧刷新不能恢复刚被取消的许可。普通网络超时/断网保留有效缓存只读；服务器尚未明确拒绝时，客户端不能凭离线状态推断权限已被撤销。读取某个新上传预留 ID 的预期 404 是创建协议内部步骤，不作为撤权。

## 图谱、试炼和个人记录

图谱只由公共案例引用的英文术语生成；节点大小表示案例数，颜色表示术语类别，细线表示同一案例中的术语共现。点击节点看真实关联案例，点击案例看原图。私密草稿和没有公共引用的预置术语不形成节点；关系不是因果结论或能力评分。

默认试炼随机抽取当前范围内具有有效多图顺序或单图分界的案例，跨重启尽量避开最近 20 例（小题池按数量缩短窗口）。先保存判断，才可显式揭示后续阶段；标题和事后描述不提前显示。截图中原有的文字/画线可能提示答案，所以只称“截图练习”，不称严格盲测、历史 K 线回放或自动评判。

公共案例总量、个人贡献、明确“记为已研究”的案例数、个人主题笔记和判断分别统计。打开案例只恢复最近研究，不增加掌握度。账号学习记录写入 Store 中按认证 permissionId 隔离的 DPAPI 加密记录，不进入共享文件。换账号后，查询、原图案例页和成长接口均重新按当前身份取个人记录；不只依靠前端隐藏。

“备份与恢复”保留原有私密案例 ZIP，并新增账号个人学习的 `.palearn` 加密备份。后者必须在本机同一 Windows 用户下、登录同一 Google 账号后才能恢复，不能当成跨电脑迁移包。恢复按记录 ID 合并，冲突或身份不符明确拒绝；不覆盖已有有效记录。活动学习记录无法解密时，明确选择本人备份恢复会先逐字保留异常密文到 meta 诊断，再恢复已校验的内容；正常写笔记不会覆盖异常记录。公共案例引用使用稳定 ID；本机私密案例的学习引用依赖原运行库身份，ZIP 恢复为新案例副本不会自动改写这些独立账号记录。换机学习迁移尚未实现，应保留原运行库及 Windows 用户的数据备份。

旧私密案例及其原有笔记/判断继续按本机 owner 保留；不自动认领到 Google 账号，也不自动公开。登录后成长页显示账号学习并标明来源，计数与当前账号记录一致；本机历史仍可在私密案例页查看。断开后成长页显示本机记录，并提示账号记录需连接原账号查看；不自动合并或迁移两套记录。schema 保持 9，没有新增表、启动迁移或安装更新门禁变更。原案例 ZIP 的校验、异常试炼设置隔离和恢复规则不变。

## 验收边界

隔离双身份协议、真实 Windows WebView、真实 Google 单账号和多账号是不同证据。2026-11-04 本人桌面 OAuth 已完成，真实 Google 单账号三组双图样本上传、原字节下载、搜索/术语/图谱/本机笔记隔离和进程重启通过；已归档九张该轮真实运行截图。第二位成员访问、两个真实账号一致性、真实断网及 Google 撤权、长期运行仍未验，不能称团队已上线。先前 Windows 拼音实际按键及自动 composition 回执分别保留，不用模拟结果替代真实 Google 结果。

实现依据：[Brooks 官方术语表](https://www.brookstradingcourse.com/price-action-trading-terms-glossary/)、[Google 桌面 OAuth](https://developers.google.com/identity/protocols/oauth2/native-app)、[Drive 上传协议](https://developers.google.com/workspace/drive/api/guides/manage-uploads)、[预分配 Drive 文件 ID](https://developers.google.com/workspace/drive/api/reference/rest/v3/files/generateIds)。词库只采用精简英文名称和缩写，不复制长篇课程内容。
