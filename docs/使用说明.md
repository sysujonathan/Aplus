# A · 给交易员的使用说明

## 你控制判断，工具负责记录和计算

这个工具不连接券商、不提交委托、不要求 TradingView 密码。策略输出的是观察线索，计划是否成立、是否交易始终由你判断。

## 第一次使用

1. 双击桌面 A 文件夹中的“启动A.cmd”。
2. 进入“市场数据”，勾选要更新的板块：沪深主板、创业板、科创板、北交所。默认选择前三个板块，从 2016 年开始留存日线。当前 BaoStock 未接入北交所，勾选时会明确提示；也可以导入自己的 CSV。
3. 网络暂时不可用时，生成演示行情熟悉流程。演示数据明确隔离，不能代表实际效果。
4. 切到“日常扫描”，选择行情来源、周期与策略，点击“匹配策略”。扫描继承市场数据页勾选的板块，仅使用这些板块已保存股票的最新行情；切页和重启保留板块选择。进度显示股票数量，策略计算次数另列。例如 3196 只股票、2 个策略，股票进度分母为 3196，计算总次数为 6392。缺少本地行情的股票不会虚算进可扫描数量。左侧按“市场数据→日常扫描”排列，首次打开先进入市场数据。
5. 任务结束后点击“刷新结果”，先检查失败数量，再查看候选。

## 场景一：收盘后日常操作

扫描结果可按策略分类，分类标题显示命中数量。点击结果表的股票行查看 K 线，或使用“上一只 / 下一只”连续翻图；“导出当前分类 CSV”只导出当前筛选结果。图上参考线直接显示对应价格数值。

市场数据同步 → 策略匹配 → 展开机会 → 打开 TradingView → 自己分析并制定计划 → 人工交易。

图上的入场、止损、目标只是策略参考；你可以在“我的交易计划”另填自己的价格、股数和判断，不会改写策略。自己的状态“已手工入场”不代表工具替你成交。交易日期、实际成交价及复盘可填入备注；本版没有券商成交对账。

同一只股票的不同策略或周期分别保留。H2 持续提醒会定位原始形态日期，重复保存同一机会的计划会更新而不重复建单；每次修改另存历史。

行情日期以每条结果的“行情日”为准。扫描不会自动补行情：使用一周前的快照就只能说明一周前的信号。工具不会将停牌或供应商延迟伪装成最新数据。

每日 19:00（北京时间）之前默认不使用当日行情，避免供应商尚未更新完整。周线由日线合成，只纳入周五日期已到的完整周；节假日所在周会保守等到周五之后。TradingView 的复权和周期可能不同，请核对后再比较。

## 场景二：回测研究

选择行情快照、策略、周期、日期和研究条件 → 回测 → 查看逐笔记录及假设 → 人工判断是否值得进一步研究。

研究条件中的最低分数、最低盈亏比、等待期、持有期和费用仅影响这次研究，不修改原策略。不同策略原始分数的量纲不一致，不能将不同策略的同一个分数视为相同质量。

### 必须理解的统计口径

- 每一步只将当时已完成的 K 线交给策略，指标也重新计算；热身至少 125 根，每次至多使用 300 根。
- 每个形态首次观察时固定其入场、止损和第一目标。**不模拟 H2 后续动态下移挂单**；这是统一的“信号研究”口径，不宣称复刻原项目的所有回测行为。
- 信号收盘之后才允许入场；最早下一根 K 线退出。日线使用这样的隔日退出约束；周线/月线更保守，并非精确日内成交模拟。
- 同一根碰到止盈和止损按止损；缺口按不利开盘价处理；入场价已越过目标时跳过；单一价格或零成交量 K 线不成交。
- 不模拟排队、精确涨跌停规则、券商最低费用、全部交易费用、分批买卖及资金约束。默认费用只是可修改的假设，不是收费查询结果。
- 到样本末尾仍未结束的交易单列，不强制变成盈利或亏损；没有已结束样本时不显示虚构胜率。
- 各信号独立评估，可以重叠。平均收益率是逐笔样本统计，**不是组合收益率、年化收益或真实可赚的钱**。
- 当前股票名单没有退市历史全集，存在幸存者偏差。前复权历史数据也不等同于历史当日真正发布的数据版本。

每份报告固定引用行情快照和策略版本；以后重新同步不会改写过去的报告。若比较不同参数，请同时核对样本范围、行情版本和费用条件，不只看胜率。

## 场景三：开发和注册新策略

在“策略工厂”下载接口示例，交给开发者编写。新策略是独立单文件，原策略不动。你确认文件可信后上传、填写类名及构造参数，注册为研究版本。

新策略先完成接口验证，再在真实行情上回测；当前版本至少有一笔结束样本、研究无失败项，才能由你填写理由并确认启用。这个门槛仅说明流程走通，**不证明策略有效**。启用和退回研究区都留记录。

新参数用新注册版本，不覆盖旧插件文件。插件能执行本机 Python，不是安全沙箱；不要上传来源不明的代码。

## 当你想知道系统在做什么

“运行与文件”列出任务开始、策略调用、行情读取、结果保存、失败原因和人工决定。运行途中可停止，当前请求或计算结束后生效。意外关机后未完成的任务显示“上次中断”，可重新发起，不自动宣称成功。

行情下载等待可通过停止按钮打断。登录超过 30 秒、单次查询超过 60 秒会终止卡住的连接；连续三只失败或被数据源封禁时停止整批并说明原因。已保存的行情保留，下次同步会复用。这里追踪的是工具自己的操作，不监视资源管理器或其他软件。运行目录中的数据库、历史行情和人工计划不是可随意清空的缓存。

## 常见问题

**扫描中断后重来？** 行情快照、策略版本、周期、截止日期及计算程序版本完全相同，已完成的判断自动复用（包括未命中）；只重算未完成和失败项。每项完成都会保存回执，停止后仍能查看累计命中、错误和进度。数据、日期或策略变化会重新计算。升级前没有逐项完成记录的旧任务无法可靠续接，旧命中仍保留；首次使用新版计算后即可复用。

**重复同步会重新下载吗？** 默认不会。相同或更小范围直接复用；截止日期延后只补新增行情，历史起点提前只补较早历史。为核对复权，补齐时会额外读取衔接处一根已有 K 线，发现价格变化才刷新该股票完整历史。勾选“重新核验并刷新历史”会主动重新下载，请仅在怀疑数据有误时使用。原快照和已生成的报告仍保留。

**中途停止后怎么办？** 再次选择原来的范围并同步，成功保存的股票会跳过，未完成的继续下载。周末、停牌或供应商尚未发布数据时，末尾没有行情的日期可能再次核对，但不会重下整段历史。回执分别记录跳过、新下载、补齐、历史刷新和失败数量。

**板块怎么选？** 勾选的板块才更新，可同时选择多个。取消某板块不会删除已有行情。首次使用自动获取股票目录；新股上市后可展开“股票目录”更新。目录只是系统识别板块股票的内部清单，不等于行情，也不是退市股票历史全集。同步页面不再保留默认三只股票或手填代码的入口。选择某板块但目录没有对应股票时会阻止提交，并明确提示，不会悄悄漏过。

**没有信号？** 先看回执：成功但未命中、历史不足、计算失败是不同情况。

**同步失败？** 看具体错误，可以重试或导入 CSV。联网服务可用性不由本工具保证；不会悄悄换成演示数据。

**周线历史不足？** 同步更早的日线历史，再扫描；至少需 125 根周线。

**回测较慢？** 逐日重算是为避免未来信息。先少量股票、短日期检验问题，再扩大范围；进度会显示当前股票与根数。

**浏览器关了？** 双击启动文件重新打开；本地服务可能仍在运行。要退出整个服务，先停止进行中的任务，再运行停止脚本。
