# Aplus · 快速上手

顶栏“版本更新”先告诉你是否需要更新，并显示正在运行的版本和正式版。发现可安全更新的新版时，点击醒目的“立即更新并重启”；缓存结果会由程序在后台自动重新确认，不需要自己再点一次，也不需要执行PULL。暂不能更新时按窗口提示处理。“使用说明 → 更新日志”可按版本查看每次改动，标为“预览”的修复还不是正式发布版。

## 每天怎么用

1. 双击“启动A.vbs”打开桌面版，在“盘前任务”选择板块、行情来源和日线／周线。
2. 点击绿色“一键”，自动复用已有行情、补拉普通价格缺口并扫描。断网／中断后再点即可续做，不必先手动补拉；等进度结束后看回执，不把“部分完成”当成全部数据齐全。
3. 查看右侧候选和左侧 K 线。需要只更新或只重新判断时，仍可分别点“更新行情”／“策略扫描”。信号只是观察线索，不代表已成交，也不会替你下单。

## 缺口要不要等

“可扫描”股票可以先扫描，不必等全部缺口补齐。“缺口处理”按历史缺日、停牌、新股历史不足、身份问题等分类；先看详情，再选择补拉、状态核验、忽略统计或待定。忽略只隐藏提醒，不会放宽扫描资格；未知缺口仍排除该股。

一键自动补拉只处理扫描需要的普通价格缺口，不反复碰停牌、新股历史不足或身份异常。供应商限制访问时停止并等待冷却；补拉成功但内容没改善时保留待查，不循环下载。行情已齐而策略换版，只重新计算受影响的判断。黄色“×2”只表示所选范围内两个不同交易日命中，同一天重扫不累计。

行情日已经到最近收盘，周末不需要重复下载。历史日期的缺口窗口可查看；补拉时切回最近交易日。若显示“范围待核验”，先核对所选日期与来源：日历漏了真正的交易日、股票目录未核验等情形才需重新更新行情。

## 更新行情 ≠ 更新软件

“更新行情”获取股票数据，不升级软件。三源独立保存，切换来源不会拼接价格。下载进度中的日期是实际请求范围：“获取历史”是初始化历史；“更新尾部”只补新行情并核对衔接日。TickFlow／腾讯首次日线默认准备两年，更早研究历史需要显式下载；只改回测日期不会自动下载。

顶部右侧“版本更新”检查软件代码。扫描提交后每天后台最多检查一次；有已通过验收的主线新版，程序先在后台自动重新确认，再在任务结束、编辑窗口关闭后提示“立即更新并重启／稍后”，同一版本不反复提示。你确认后才更新。未合并 PR 不属于可更新主线；开发分支和本地修改需维护者核对，不能强行 PULL。

## 登记交易

“交易管理”中新增持仓，除了计划的止损／目标位，还要填写下方实际买入日期、成交价和手数；一手为 100 股。尚未实际买入不要当持仓登记。券商成交、清仓及资金变动由你确认录入；初始资金推算用于对账，不固定为某个数。

## 更长历史与回测

盘前“更新行情”菜单可选择“完整历史（2016 年起）”；Web 市场数据可指定更早起点。先下载，再在“盘后回测”选择来源和日期。周线至少需要 125 根已完成周 K。腾讯不复权，BaoStock／TickFlow 前复权，跨除权信号和收益不保证完全一致。

## PA 成长空间

顶栏打开“PA 成长空间”，Ctrl+V 粘贴、拖入图片或批量导入。未填资料可“存草稿”；“保存案例”选择至少一个英文 Brooks 术语。标题和长篇复盘不必填写。批量默认每张图独立成案，需要时才组成多图案例。原图按原字节保留，重复图明确提醒，保存失败保留待存内容。

保存成功先进入本机私密列表，重启仍可找回。旧案例、笔记和判断不自动公开。打开私密案例，点“提交到公共空间”，核对共享范围后才上传到指定 Drive 目录；原图和案例全部验证后才提示已提交。公共案例保留贡献者和原始提交，个人研究与判断留在当前账号的本机安全存储中。当前 Google 授权及团队共享仍需负责人配置，步骤见 [PA共享知识空间](PA共享知识空间.md)。

“公共案例”和“私密草稿”直接切换。公共检索可筛选“我上传的案例”，不是另一份个人公共库。搜索品种、关键词、英文术语或自己的研究，支持部分匹配；`H2` 和 `High 2` 为同一术语，`GAP H2` 不会混同。点击缩略图看原图，缩放、拖动、Esc 返回原搜索结果。盘前图表旁“案例搜索”并排打开历史图，返回保留标的、周期、画线和视野。

公共案例点击“刷新”发现新贡献；界面显示缓存时间。断网可看已经缓存的资料，未下载原图会明确提示，离线保存不代表已同步。公共案例总量与个人贡献分别呈现。标准术语共现生成共享知识图谱；没有公共引用的词不显示，私密草稿不进入图谱。点击术语找到真实案例，拖动、滚轮或按钮缩放和定位。

“PA 交易试炼”默认随机抽取当前范围内已设置渐进呈现的案例。私密案例“设置试炼”可选择两张以上的入场/后续截图，或标记单图分界；普通收录不必设置。先保存判断，再明确“揭示下一阶段”，放大也遵守同一阶段。最近抽过的案例尽量不重复。截图已有文字、价格标记可能提示答案，本功能是截图练习，不是严格盲测或完整行情回放，没有自动评分。

每案例最多 100 张、原图合计 128 MiB；旧超限备份可完整恢复和查看，只限制继续追加。“备份与恢复”保留私密案例 ZIP，恢复生成新案例、不覆盖正式交易资料。账号个人学习另有加密 `.palearn` 备份，只能由本机同一 Windows 用户登录同一 Google 账号恢复；不能作为换机迁移包，详见共享说明。备份提示异常试炼设置时，原图与有效研究仍保留，打开案例重新设置即可。旧版无效活动配置的 ZIP 仍需从原库重新导出。

## 退出与数据保护

关闭桌面窗口通常只是隐藏到托盘；真正退出需右键托盘图标选择“退出”。人工更新代码后必须完整退出再启动，运行中的程序不会自动换成新代码。

不要删除 runtime 或把它当临时缓存清理：里面有行情、交易、计划和研究记录。软件更新保留原数据位置；代码备份不等于个人数据备份。
