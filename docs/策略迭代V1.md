# 策略迭代 V1：初始止损对照

## 板块分工

盘后回测运行已经明确的策略方案及其可配置参数；策略迭代验证交易规则的改变。研究分类按 PA 交易生命周期组织：背景与形态、入场与初始风险、等待与持仓管理、退出。四类共享实验记录、方案对比与差异样本复盘。

本版只接通「入场与初始风险」中的 GAP H2 初始止损对照。其他三类显示为规划入口，不能运行。没有新增实盘启用或下单功能。

## 使用流程

1. 在盘后回测运行一次 GAP H2 日线回测。回测可以是完整或部分结果；部分样本的研究仍显示为部分结果。
2. 打开策略迭代，选择这份回测作为样本。机会、原模拟成交、MM、持有期限及费用全部固定。
3. 设置候选 C 的回溯上限和浅回调容忍，点击新建实验。本版默认 30 根、0 tick。
4. 看结果分类与逐笔 K 线。默认只显示 H2 当日之前的行情，可切换事件日期；完整走势明确标为事后。图表支持滚轮缩放、拖动价格轴和鼠标查看 OHLC，成交量沿用 7:1 的压缩比例。
5. 每次实验独立保存，可重命名、移至已删除并恢复。按住 Ctrl 选两次实验进行对比，要求两次使用同一源回测。平均变化仅使用两次都可对照、两个方案都结束的共同样本。

## 候选 C V0 的定义

只使用原 BO 当日及之前的价格，向前寻找低点不下降的区间。当前低点比前一根至少低「容忍 tick + 1 tick」时，找到分界；取这个区间内的最低点下方一个品种 tick 作为候选止损。不以阴阳线颜色分腿，不使用 BO 后的回调或事后盈亏来选择底部。

找不到分界、触及回溯边界、候选段不足两根、C 不低于缺口下沿或不宽于原 SL1 的样本均单独展示为无法对照。原机会没有模拟成交也保留，不纳入配对统计。

此规则只识别候选底部，**未量化强突破**。连续抬低较长时可能识别成上涨通道；不能把它叫作已经验证的 Brooks 强突破腿。浅回调容忍以交易品种 tick 计，不默认所有证券都是 0.01。

## 如何读结果

逐笔复盘的事件标注分别以“SL1 ·”和“C ·”标识两套路径：原方案退出后，候选方案之后的 MM、止损或到期退出仍会画在对应日期和成交价格上。两套路径用上下错开的灰白标签与实线／虚线引线区分，同日成交也分别显示。持仓、T+1 或成交受限只提示当前所选事件日，避免每个持仓日都挤满图。完整走势可展示事后行情，但事件标注仍只显示截至所选日期的事件，不提前显示之后的候选退出。

- 宽止损救回：原 SL1 止损，候选 C 方案在同一持有期限内到 MM。
- 两者到 MM：放宽止损没有增加一笔到达 MM 的交易。
- 两者止损：重点看宽止损扩大的损失。
- 仍持有／其他退出：含到期退出，不能算作被救回。
- 无法对照：显示原因，不能静默排除以美化结果。

平均差异以原 SL1 的初始价格风险为统一 R 分母，只统计两方案都已结束的配对样本；各方案自身 R 保存在研究结果中。未结束交易不记作零收益。研究不是组合收益，也没有模拟组合仓位、资金约束或复利。

T+1、停牌／单一价格、跳空、滑点、税费、同日双触碰与持有期限沿用源回测。执行对照会先复现原方案退出；旧报告不能复现时单列无法对照，提示重新回测。源回测用原始 SL1 决定的未成交机会，不会因为研究止损更宽而补造新成交。

## 数据与验收

实验使用 Service 的后台队列，报告及逐笔结果通过 Store 写入研究文件，名称和删除状态复用 Store 的回测元数据。无需增加数据库结构，不写 observations、plans、watchlist 或真实交易账本，冻结文件保持字节不变。

代码检查覆盖未来数据不改变候选锚点、不同 tick、T+1、双触碰、到期、配对 R、无法对照计数、历史保存恢复和图表截止日。真实数据核验应另列样本、快照校验值与结果，不能把合成工程测试作为真实验收。长期操作与交易判断仍须交易员使用验收。
