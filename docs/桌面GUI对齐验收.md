# 工程 A 桌面 GUI 对齐（2026-09-29）

本轮以原工程 gui_dashboard.py、图表样式和用户截图为参考，先恢复操作界面，业务功能待用户验收后再迭代。

## 使用

关闭旧版 Aplus 窗口，再双击本目录的 `启动A.vbs`。如果另一台电脑缺少新界面依赖，先执行 setup.cmd；依赖已锁定。

- 顶部业务栏：盘前任务、盘后回测、策略迭代、其他工具。盘前已经接入；后三个入口明确展示边界，不冒充已完成能力。业务栏不再占用整高左侧区域。
- 盘前工具栏：日/周切换、市场范围、更新行情、策略扫描、AI 复核、日期。日期栏同时包含本地行情日和已有扫描日；启动定位最近一次已有扫描日并展示命中，行情同步后新增交易日但不自动切走当前页面，扫描后也由交易员主动切换。年、月、日三级选项只列出本地真实存在的交易日，月份切换或任务完成刷新时不会混入其他月份的日号。顶部常驻区分别显示“行情最新”和“信号最新”，两者不一致时标记“待扫描”。已迁入 Aplus 的历史扫描成果继续参与历史浏览，不提供来源切换入口。运行任务时显示“终止”。
- 候选区：一次显示四个策略及命中数量，使用 `MTR / 3K / GH1 / GPb / GH2` 等短名，两侧三角切换其余策略；“序/代码/名称”按内容压缩，标题点击切换正序/逆序。当前日期范围内同一股票只显示一行，名称后显示 `×次数` 并以暖色突出；原始观察记录仍完整保留。
- 中间：默认 2×2 多股 K 线，可切换单格、六格或九格；蓝色标题条和边框表示活动图。每格采用低眩光深色画布，保留红涨绿跌 K 线、琥珀色 EMA20、成交量、原策略信号星标、蓝色止损与红色目标线，并有独立 TradingView 入口。价格直接在图内标注，不再在图下重复显示一遍。
- 右侧：关注列表显示“序/代码/名称”；单击替换活动图，拖入某个图格只替换该格；K 线使用该股票最新 Aplus 正式行情，原观察记录保留为“为何关注”的信号锚点，图格标题同时显示行情日、信号日及“计划线来自信号日”，避免把原入场/止损/目标误认为最新行情重新计算的计划；原有备注、计划状态和结束关注仍通过右键菜单使用。
- 底部：蓝色 TradingView 按钮和任务状态。
- 空仓首次点击“更新行情”或旧数据尚未覆盖到 2016 年时自动补齐完整历史；完整覆盖建立后自动只补缺口。原“完整历史”选项保留在更新行情按钮的右键菜单，用于人工要求重新核对更早范围。市场范围选择同时约束更新与后续扫描。
- 关闭与重复启动：窗口关闭后驻留系统托盘；托盘菜单只保留“打开主界面”和“退出”，双击托盘图标直接恢复。已运行时再次双击 `启动A.vbs` 只提示，不创建第二个实例。

界面使用 ttkbootstrap 1.20.1 darkly 主题并覆盖统一石墨色板，交互强调色为 #2F81F7，图表采用 mplfinance。图表先按观察日期裁剪、按周期聚合，再调用冻结策略计算显示信息，避免历史图混入未来行情或周线页面误画日线。

## 验收记录与边界

- 完整代码测试：80 passed；4 条现有 pandas/NumPy 弃用提示。
- Python 依赖：pip check 通过；冻结文件、数据库结构与 Service 未修改。
- 实际窗口：使用此前已导出的工程 A 行情，在隔离目录运行历史 MTR 命中，检查 K 线、详情、候选选择和关注读取。
- 几何检查：1280×760、1600×1000、2800×1700 下日期控件可见，图表与关注区不重叠。
- 预览为 sh.600000 的真实历史信号，不是当前交易日或全市场结果。未迁移旧工程的股票目录、信号档案和个人关注记录，正式环境空列表仍会显示为空；没有名称数据时不编造名称。
- AI 复核保留界面入口，但 Aplus 尚无对应后端，点击会说明并恢复关闭；不发送外部请求。原工程的周线“待建仓”专用数据入口尚未接入 Aplus，本轮未用虚构内容补齐。
- 用户尚未确认像素细节及完整操作体验；联网同步、全市场扫描、长期实际使用未验收。本轮不增加回测工厂或知识库功能。

## 建议用户依次核对

1. 最大化窗口，对照原工程的布局、颜色、列表宽度和字体。
2. 切换日/周、策略和日期，检查候选与图表；空列表应清空旧图。
3. 选中真实候选，检查 K 线、成交量及图内价格线；右键加入关注后从关注列表再次选中。
4. 点击底部按钮检查 TradingView 跳转；关闭窗口后从右下角托盘恢复，再从托盘右键退出。

界面认可后，再安排行情同步和全市场功能验收。
