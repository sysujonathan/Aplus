# 工程 A 桌面 GUI 对齐（2026-09-29）

本轮以原工程 gui_dashboard.py、图表样式和用户截图为参考，先恢复操作界面，业务功能待用户验收后再迭代。

## 使用

关闭旧版 Aplus 窗口，再双击本目录的 `启动A.vbs`。如果另一台电脑缺少新界面依赖，先执行 setup.cmd；依赖已锁定。

- 顶栏：Brooks-AI 操盘台、日/周切换、代码送 TradingView、策略扫描、下载行情、AI 复核、信号日期。运行任务时显示“终止”。窄窗口自动将操作控件换到第二行。
- 左侧：竖向策略按钮及数量，独立的“序/代码/名称”候选清单，支持键盘选择及右键加入关注。
- 中间：白底红绿 K 线、橙色 EMA20、成交量、原策略信号星标、蓝色止损与红色目标线；下方显示策略、股票、触发价/止损价/目标价/信号日。
- 右侧：关注列表显示“序/代码/名称”；原有备注、计划状态和结束关注仍通过右键菜单使用。
- 底部：蓝色 TradingView 按钮和任务状态。
- 原“完整历史”选项移到下载行情按钮的右键菜单，仍默认近两年。

界面使用与原工程相同的 ttkbootstrap 1.20.1 darkly 主题及 #007AFF 强调色，图表采用 mplfinance。图表先按观察日期裁剪、按周期聚合，再调用冻结策略计算显示信息，避免历史图混入未来行情或周线页面误画日线。

## 建议用户依次核对

1. 最大化窗口，对照原工程的布局、颜色、列表宽度和字体。
2. 切换日/周、策略和日期，检查候选与图表；空列表应清空旧图。
3. 选中真实候选，检查 K 线、成交量及价格详情；右键加入关注后从关注列表再次选中。
4. 输入股票代码及点击底部按钮，检查 TradingView 跳转。

界面认可后，再安排行情同步和全市场功能验收。
