# 模块测试地图

本地图用于快速选择定向测试，不替代 [修改约束](修改约束.md) 或 GitHub 必需 CI。先运行最贴近改动的测试；共享契约或影响范围扩大时，再加入相邻模块回归。

| 模块 | 主要代码范围 | 优先测试 | 需要扩大验证的情况 |
|---|---|---|---|
| GUI 主窗口与布局 | `gui/main_window.py`、`gui/toolbar.py`、`gui/candidate_panel.py`、`gui/watch_panel.py` | `tests/test_desktop_layout.py`、`tests/test_display_refresh.py`、`tests/test_native_ui_setup.py`、`tests/test_toolbar_status_layout.py` | 改动键盘操作、选中状态或跨面板刷新时，补 `test_startup_manual_watch.py` 和相关 chart 测试 |
| K 线与图表 | `gui/chart_panel.py`、`gui/chart_rendering.py`、`gui/theme.py` | `tests/test_chart_workspace.py`、`tests/test_chart_annotations.py`、`tests/test_chart_snapshot.py`、`tests/test_desktop_chart.py` | 改动策略标注语义时按 A11 覆盖对应策略，并执行真实观察渲染检查 |
| 行情同步 | `workbench/market.py`、`workbench/sync.py`、`workbench/sync_batch.py`、供应商模块 | `tests/test_incremental_sync.py`、`tests/test_baostock_selective_sync.py`、`tests/test_baostock_daily_batch.py`、`tests/test_sync_progress.py`、`tests/test_market_recovery.py` | 改动超时、重试、来源切换或覆盖事实时，补 `test_provider_timeout.py` 及对应 TickFlow/腾讯来源测试 |
| 策略扫描与盘前任务 | `workbench/service.py`、`workbench/readiness.py`、`workbench/strategies.py`、扫描编排 | `tests/test_scan_preflight.py`、`tests/test_scan_scope.py`、`tests/test_scan_resume.py`、`tests/test_scan_bulk_prefetch.py`、`tests/test_flows.py` | 改动恢复、检查点或盘前编排时，补 `test_premarket_flow.py`、`test_premarket_resume.py`、`test_premarket_checkpoints.py` |
| GAP H2 | H2 适配、计划与回放调用链 | `tests/test_h2_plan.py`、`tests/test_h2_replay.py`、`tests/test_h2_performance.py`、`tests/test_watch_gap_anchors.py` | 触及冻结策略或标注契约时按 R3 处理，并覆盖版本、清单与计算对照 |
| MTR | MTR 适配、信号柱与获批版本调用链 | `tests/test_mtr_signal_bar.py`、`tests/test_approved_strategy_update.py` | 触及获批策略文件、版本或清单时按 R3 处理，并执行完整策略安全验证 |
| Store 与人工状态 | `workbench/store.py` 及其调用者 | `tests/test_store_update_compatibility.py`、`tests/test_trade_management.py`、`tests/test_account_reconciliation.py`、`tests/test_flows.py` | schema、迁移、去重身份或正式账本边界变化时按 R3 处理，加入旧数据兼容和完整回归 |
| 回测与研究 | `workbench/backtest.py`、研究工作区、报告链路 | `tests/test_backtest_history.py`、`tests/test_workbench.py`、`tests/test_research_workspace.py`、`tests/test_stop_research.py` | 改动未来数据隔离、快照血缘或正式表写入边界时，补端到端隔离与扰动测试 |
| 软件更新 | 更新检查、版本、回执和桌面提示模块 | `tests/test_version_update.py`、`tests/test_update_review_safety.py`、`tests/test_update_notice_help.py`、`tests/test_release_versions.py`、`tests/test_update_receipts.py` | 改动更新锁、恢复或发布安全判断时，补相邻 Service/启动保护测试 |

以下情况通常需要在定向测试之外运行完整本地回归：冻结策略或清单获批变更、数据库 schema 迁移、关键共享接口的大范围修改、依赖或测试基础设施变化，以及定向测试无法隔离影响。纯文档和无业务行为变化的 CI 治理按 R0 做静态检查即可；其正式效果由 PR 的 GitHub 必需 CI 验证。
