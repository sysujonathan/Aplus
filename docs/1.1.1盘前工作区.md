# 1.1.1 桌面盘前工作区

## 交易员看到的变化

- 左侧新增四个业务板块：盘前任务、盘后回测、策略迭代、其他工具。当前盘前页完整可用；其他板块先建立独立入口并说明能力边界。
- 盘前操作顺序调整为“选择市场范围 → 更新行情 → 策略扫描”。沪深主板、创业板、科创板、北交所可分别勾选；同一选择同时约束行情更新和扫描范围。
- 策略导航从竖排改为横向排列，名称和数量分两行，简称仅用于显示，不改变正式策略名称、策略文件或观察记录。
- 候选列表的序号、代码和名称统一居中；点击列标题可切换正序和逆序。
- 选择全部信号或较宽日期范围时，同一股票重复出现会在名称后显示 `×次数`，并使用暖色突出。原始信号仍逐条保留，不合并、不删除。

## 不变的边界

- 候选区与全部信号区域宽度保持原桌面布局范围，不挤占 K 线主区域。
- 原策略、冻结清单、数据库结构、增量同步、完整性检查和中断续跑逻辑不变。
- 北交所是否能够更新仍取决于当前行情供应商和股票目录；目录没有该板块时会明确报错，不会伪装同步成功。
- 盘后回测、策略迭代、AI 辅助和盘中工具本轮只建立桌面分区，不改变或虚构后端能力。

## 验收口径

1. 四个业务板块可以切换，回到盘前页后已有候选和图表状态不丢失。
2. 策略标签不超过原候选区；名称与数量分行显示。
3. 三个候选列均居中，连续点击同一标题时排序方向交替。
4. 日期选择全部时，重复股票显示次数；切到单日后按该日结果重新统计。
5. 勾选不同市场范围后，更新任务和扫描任务提交相同板块集合；未选择板块时不允许启动任务。
