# 1.1.0 交易工作台

## 交易员看到的变化

- 深色默认界面；同步与扫描同页，候选、K线、持续关注并排。
- 删除日常导入行情、数据清单和手动更新目录入口；研究记录与原行情不删除。
- 日线默认勾选，可以加选周线；策略勾选，自动按原策略支持周期分配。
- 关注列表跨重启、跨扫描批次保留，支持笔记、结束与恢复；不会自动生成计划。
- 关注看最新本地行情，原信号日期始终显示。复权变化时隐藏旧价格线。

## 数据边界

同步先取交易日历、当日股票目录和证券基础档案，交叉核验上市日、退市日和交易状态。新股加入、名称变动随目录更新；停牌不伪造K线；确认退市只从当日范围排除，不清理历史。未解释的缺失、状态矛盾、接口短响应阻止目录更新和后续扫描，而非猜测原因。

当前 BaoStock 不覆盖北交所，界面明确报缺口；不能宣称覆盖全部A股特殊情形。证券档案依赖供应商质量，不以股票名称或一次缺失推断退市。历史回测仍有历史股票池完整性限制。

## 工程约束

原策略与冻结依赖完全不改。新增 workbench/dashboard.py 仅编排界面；service.py 编排多周期任务。已完成的各周期判断持久保存，停止后同条件重扫复用缓存。仅支持日线的策略不强行套用周线。

数据库从版本3自动升级到4，只新增 watchlist 表，不删除行情、信号、计划。关注按股票去重，锚点引用 observations；归档使用 active 标记。正式部署先备份数据库和替换文件。用户自行提交 GitHub。

自动测试覆盖目录新增、停牌、明确退市、缺失不能冒充退市、未来上市日、关注持久化、无自动计划、版本迁移及多周期中断续用。真实接口另做隔离目录交叉核验，不替用户启动全市场同步。
