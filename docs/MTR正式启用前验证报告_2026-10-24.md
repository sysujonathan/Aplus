# MTR 正式启用前验证报告（2026-10-24）

## 结论先行

在 main `036b0676c3affe293255dcd33ac56be3aeb1a355`、Windows / Python 3.14 / NumPy 2.4.1 / pandas 2.3.3 的精确白名单环境中，MTR SHADOW **确实进入 SHADOW，没有静默回退 OFF**。

对 300 只来自用户 Aplus 数据仓的真实 BaoStock 日线、5 个历史交易日进行了 1,493 次有效前缀比较，其中包含 9 个真实 MTR 正式信号。完整 payload、setup 日期、Entry、SL1、TP、评分、风险提示及机会身份差异均为 **0**；原版业务异常为 0，未触发熔断。

本轮证据足以支持申请“当前精确 Windows 环境、先 SHADOW 后小比例 canary”的人工审批，但**不足以批准默认 ACCELERATED 或跨所有数据源直接启用**。仍缺真实 TickFlow 同范围对拍、正式完整性门禁后的全可扫池运行及约 2,800 根真实长期仓验证。

## 验证边界

- 本报告既有原始运行以 SQLite `mode=ro&immutable=1` 读取，成立前提是源库静止；收尾加固后的工具改用 `mode=ro`、`query_only` 和只读事务快照，读取时遵循 SQLite 锁及 WAL，不再要求“文件绝不变化”。既有原始 JSON 和计时没有改写；后续重跑时行情文件仍逐一核对登记 SHA-256，数据库登记与文件不同步会安全失败。
- 选中行情复制到一次性临时 Store 后才执行扫描、缓存、观察记录和事件写入。
- 未联网、未补拉行情、未修改源 runtime、未修改冻结策略或 `frozen_manifest.json`。
- 源仓为 schema 4，包含 5,211 份 BaoStock 日线；其中 5,165 份不少于 125 根，行数中位数和最大值均为 486。源仓没有 TickFlow 快照，也没有约 2,800 根真实长期历史。
- 源仓 `market_quality:*` 记录为 0；因此这些是真实业务行情快照，但不能冒充已经通过当前正式质量门禁的“正式可扫池”。
- 仓库内未找到此前 Golden Corpus 或第三阶段真实样本的可执行工件。本轮改用按股票代码排序后等距抽样的确定性真实样本，可由工具重复生成。

## 六策略真实短历史统一基线

使用 60 只真实 BaoStock 快照、每只约 486 根、六个冻结策略、隔离 Store，OFF / SHADOW / 隔离授权 ACCELERATED 采用三轮交错顺序。计时包含逐文件读取、SHA-256、完整 CSV 解析、300 根计算视图、公共指标、六策略、逐股耐久事务、有界回执和终态保存；不包含行情网络更新和正式 `market_quality` 预审。

| 模式 | 冷扫描中位数 | 相对 OFF | 完全缓存命中 | Python 峰值 | 事件数 | 事件 detail | 数据库大小 |
|---|---:|---:|---:|---:|---:|---:|---:|
| OFF | 19.760 s | 基线 | 0.408 s | 4.643 MiB | 426 | 62,399 B | 452 KiB |

### 已验证事实

1. 当前精确 Windows 环境和冻结版本绑定有效，SHADOW 没有回退 OFF。
2. 300 股、5 日、1,493 次真实前缀比较含 9 个信号，完整业务结果零差异。
3. 真实 60 股六策略短历史中，隔离授权加速墙钟减少 27.7%，业务摘要一致。

### 仍未验证

1. TickFlow 真实行情同范围结果。
2. 经过当前完整性、停牌和质量门禁后的 4,000+ 正式可扫池全量 SHADOW。

4. 行情网络更新及完整一键盘前端到端耗时。
5. 跨更多交易日的长期运行和真实可达业务异常。
6. 当前历史日期选择仍取样本共同最晚日期；长期停牌或旧快照可能把日期拖早。下一轮全可扫池 SHADOW 必须逐股核对目标日有效性，不能简单换成中位数或分位数后把旧股票算作目标日正式扫描对象。
