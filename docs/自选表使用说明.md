# 自选表使用说明

依据用户附件《TradingView使用说明书》第六章调整 Aplus 关注入口；管理证券视图，不创建假扫描信号，不自动下单。

- 顶部下拉选择「全部关注」或命名自选表，可新建、改名、调顺序、删除命名表。删除命名表不删除全局关注、交易或画线。
- 输入代码／名称筛选，Enter 加入当前表；也可点 `+` 搜索添加并填备注。已有策略关联和备注不被重复添加覆盖。
- 单击打开活动图，拖出可放入指定图格，列表内拖动排序；表头点选排序、再点反向，「⋯」可恢复手动顺序。上下键逐股、Enter 打开、左右键整组翻页；分组标题不触发换股。
- 右键提供七色标记、添加到其他表、备注、人工分组标签、既有计划状态、结束关注。实际持仓状态来自账本；不以计划状态冒充持仓。
- 悬停显示提醒和移除按钮，下方显示完整状态／备注。命名表中移除仅删成员；全部关注中移除等同结束关注，先确认。清除颜色会影响其他表的同一标的，先确认。
- 「⋯ → 显示列」可选标记、序号、状态、备注、策略、信号日、价格、涨跌额、涨跌幅、行情时间；保留代码和名称。数字右对齐，名称左对齐，列过多时横向滚动。列表区左边缘可拖动调宽并保存。

## 行情与比较

选择行情列后先读本地历史快照。开启全局自动行情、列表可见且处于交易时段时，轮询展示集合前 80 个标的，腾讯优先，缺失／滞后时走已有新浪回退。其余标的保留历史值，可筛选到较小集合查看自动报价；不承诺无限实时订阅。

行情时间列显示来源和时间：腾讯／新浪报价、本地收盘、复权收盘分别标明。失败保留原数据及时间，不把旧价冒充实时；晚到旧历史不会覆盖新报价。ETF 显示三位小数、股票两位、未知品种四位、平均成本四位，仅改变显示。

「添加到当前图比较」使用同来源、同复权的本地日／周／月快照，以首个共同可见日期作相对涨跌幅基点叠加比较线。点比较标签可移除。无同源数据或分钟比较数据时提示缺失，不补造价格、不写正式行情。

## 导入导出和边界

导入 UTF-8 CSV 首列代码，允许“代码／code／symbol”表头，最多 5000 个、2MB。先验证全文件，再原子提交代码和表成员；失败不导入一半。已有备注和策略关联保留。导出当前筛选成员的代码、名称、备注，并处理电子表格公式前缀。

自选表成员／顺序／颜色／分组／列／宽度存在 Store 界面配置；关注、备注、计划、成交账本保持原有唯一来源。设置损坏时继续显示全部关注，保留原配置并提示。

| 附件能力 | 本轮适用边界 |
|---|---|
| 多表、搜索、排序、颜色、分组、备注、提醒 | 接入上述 Aplus 本地工作流 |
| 行情列、比较 | 使用已有可信报价／快照，范围与时间如上 |
| 市值、PE、财务、52 周统计、迷你走势 | 尚未建立完整可信数据契约；市值／PE／财务菜单明确不可用，不填示例值 |
| 经纪商下单、社交、Pine、加密市场入口 | 不属于本次关注列表任务，不新增 |

周期、绘图共享和命名布局见[多图工作区](1.1.2多图工作区.md)。
