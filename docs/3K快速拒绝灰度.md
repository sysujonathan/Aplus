# 3K 快速拒绝灰度

## 使用影响

控制器底层默认 `OFF`。2026-10-27 获批的[稳定快速版](稳定快速版.md)正常启动复用明确批准的本机配置，以 `ACCELERATED` 为目标，保留 5% 原版抽查。授权无效或精确版本、依赖、环境不匹配时继续执行冻结 3K。

快速拒绝不会跳过行情文件 SHA-256、历史质量检查、公共指标、其他五个策略或每股耐久事务。冻结 `three_k_strategy.py` 和 `frozen_manifest.json` 保持逐字节不变。

## 必要条件

正式扫描读取最后一行 `signal_3k_gap_test`。冻结 3K 对该列的赋值必经 `reversal_confirm`，而 `reversal_confirm` 必须同时满足：

1. 最新 K 线为阳线，即 `close > open`；
2. 最新收盘价严格高于前一根最高价，即 `close > previous high`。

历史 3K setup、缺口保持状态和 3—20 根确认窗口仍由冻结原版判断。快速门禁只在上述任一当日必要条件不成立时拒绝；条件成立时完整执行原版。

## 模式与授权

- `OFF`：完全执行原版；默认值。
- `SHADOW`：门禁拒绝样本仍执行原版并对拍，正式结果只采用原版。
- `CANARY`：人工授权后，仅让设定比例的门禁拒绝样本采用快速路径；其余样本继续执行原版并对拍。
- `ACCELERATED`：人工授权后采用快速拒绝，同时按设定比例保留原版抽样核验。

环境变量：

```text
APLUS_THREE_K_FAST_REJECT_MODE
APLUS_THREE_K_FAST_REJECT_APPROVED_BINDING
APLUS_THREE_K_FAST_REJECT_CANARY_RATE
```

同一个比例变量在两个模式中承担相反但明确的安全职责：CANARY 的比例是“允许进入新快速路径的比例”，ACCELERATED 的比例是“保留原版核验的比例”。因此比例为 0 时，CANARY 全部执行原版、ACCELERATED 全部走快速拒绝；比例为 1 时则相反。边界值直接判定，中间比例使用 64 位整数阈值按样本身份确定性分流，同一股票在相同身份下不会随机跳组。

CANARY/ACCELERATED 必须把目标机器即时生成的 `current_binding_id()` 作为授权值。源码、Service、`scan_cache.py`、冻结版本、依赖或运行环境变化都会生成新绑定并使旧授权失效。Store 不再绑定整个高频变化文件，而是以稳定源码片段精确绑定本功能依赖的连接、事件、序列化以及 `meta`、`events`、`scan_cache` 表契约；指纹不依赖 Python 内部 AST 字段，无关的回测历史函数变化不会误停 3K，相关持久化契约变化仍会自动回退原版。CI 通过不构成人工生产授权。

## 熔断与回退

门禁异常或输入、版本、环境不可信时自动执行原版。门禁严格要求阳线标志为无缺失的布尔列，并逐列复算冻结 3K 实际使用的 EMA20、ATR、实体、影线和收盘位置指标；文本、无穷值、非约定缺失或与同一 OHLCV 不一致的有限值均回退原版。SHADOW、CANARY 中保留原版的样本或 ACCELERATED 抽样样本若出现原版业务异常或业务结果差异，会为当前绑定写入熔断证据、切换 OFF，并停止写入该加速身份的缓存。

一键回退只需删除或设置：

```text
APLUS_THREE_K_FAST_REJECT_MODE=OFF
```

熔断后不得直接清理证据重开同一绑定；应先保留反例、完成调查和人工复核，再通过新代码绑定或明确维护流程处理。

## 复核命令

```powershell
python tools/validate_three_k_fast_reject.py `
  --source-home "<Aplus 数据仓>" `
  --output "<独立输出目录>\three-k-validation.json" `
  --quiet
```

工具只读源 SQLite，并把扫描写入一次性隔离 Store；不会联网或修改正式运行库。
