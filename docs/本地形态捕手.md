# 本地形态捕手 V1

形态捕手是盘前的另一类研究线索，使用本机已保存的真实日线行情。它不生成正式策略观察、交易计划或订单。相似度是轮廓的接近程度，不是胜率。

## 日常使用

1. 仍按原习惯更新行情、扫描量化策略。已开启每日跟踪的形态模板在行情更新后排队运行；正式业务优先，形态任务会等待，不追加行情下载。
2. 用原交易日选择器查看结果。在右上公共“匹配列表”中切换“全部／量化策略／形态捕手”，日期保持不变。
3. 次级下拉框按具体策略或模板筛选，候选行显示匹配依据。悬停列表可查看当前结果的完整模板名、相似度、区间、轮廓误差、相关系数和记录性质。
4. 单击候选沿用中央图表。右键可加入原有公共关注列表；已有关注的备注和原始策略锚点不会被覆盖，形态依据单独保留。关注后仍按原逻辑复核最新行情、绘图及管理计划。
5. 右边缘的面板图标同时收起／恢复匹配列表和关注列表。它不重开图表、不重新扫描，保留日期、来源、宽度、选择和绘图状态。

同一股票命中多个策略或模板时，列表保留多条依据。量化策略不与形态相似度合成“综合胜率”。

## 建立与管理模板

从匹配列表的“形态模板”打开低频管理窗口。“模板与每日跟踪”和“匹配结果与历史”分为两页，避免挤占盘前图表。

- **经典／文字**：六类模板为强趋势延续、底部反转、W底／双底、趋势回踩、箱体震荡、M头／顶部反转。文字仅映射已支持的关键词；含糊或同时指向多类的描述会提示直接选择，不假装理解任意 PA 语义。
- **案例／当前图表**：读取当前来源的本地真实日线，填写代码、开始日和截止K线。预览只使用截止日前数据。若没有指定开始日，预览默认最近60根。保存后保留快照编号、SHA、来源、复权、原案例引用及真实片段。
- **手绘／截图**：从左往右绘制轮廓，或在导入的截图上描绘。截图可框选主价格区，尝试白蓝／红绿蜡烛轮廓识别；识别间距和数量须通过校验，并需人工确认。失败时重新选区或手绘，不静默采用错误结果。

匹配支持30／60／120 BAR、最低相似度、结果数量、板块范围、公共关注代码或指定代码。图形先归一化和重采样，再比较收盘轮廓；并非完整 PA 结构或蜡烛语义识别。

勾选“行情更新后每日跟踪”并保存。关闭该选项再保存即可停止后续每日跟踪；已启动任务可在结果页取消。模板内容修改形成新版本，旧回执保留旧版本与当时参数。

真实行情模板与候选必须使用相同来源及该来源约定的复权口径：BaoStock／TickFlow 为前复权，腾讯为不复权；已知等价写法统一校验。新建不兼容模板或手动用它匹配时会明确拒绝，不静默换算价格。

切换行情源后，每日跟踪只运行兼容模板。来源／复权不符或截止日晚于匹配日的模板，会保留跟踪设置，并在历史回执中记录名称和未运行原因，不影响经典、手绘及当前来源的兼容模板。结果页“未运行模板”可查看完整明细；全部不兼容时也保存“未运行”回执，不把它说成未命中。

## 从成长空间发起

案例详情增加“寻找相似股票”，沿用唯一的共享知识空间和本机私有案例，不复制公共案例库。

可以查看原案例及原图标注，再关联代码与截止日。私有案例还可直接把原图带入描绘页。能关联真实行情时优先使用真实 OHLC；未关联的截图只保存无价格轮廓，不伪造 OHLC。测试案例不得用于真实股票检索。

真实行情模板可在结果右键或结果页选择“候选／原案例双图”。左图是模板截止日前的真实行情，右图是候选截止日行情，两边都复用现有图表和绘图体系。原截图的手工标注不会自动转成图表对象，可通过“返回原案例研究”查看原图。纯截图案例使用已有案例窗口与当前行情对照；经典／手绘模板没有真实 OHLC，须在模板页核对轮廓。

V1 的真实行情模板与检索均为日线。分钟截图可用于轮廓研究，不会把日线冒充分钟 OHLC。没有本地正式日线快照的品种，可以使用截图／手绘；此功能不另建下载链路。

## 历史、取消和恢复

- 同一日期、模板和记录性质展示最近一次有效运行，旧回执仍在历史页。
- 回执保留交易日、实际运行时间、模板及算法版本、参数、每股快照／SHA／复权、匹配区间、分数、跳过／失败原因和分阶段耗时。
- “当时保存”与“事后回放”分别标明。历史日回放只取截止日前的价格；不能使用截止日晚于回放日的案例模板。
- 形态候选图停在保存的匹配截止日，不接入盘中实时行情；同一股票先前的分钟缓存和切换后晚到的分钟结果也不会送入历史形态图。加入关注后，关注图按原有业务读取最新行情。
- 后台取消会保存已处理部分的回执。长任务定期保存不可变恢复点；意外退出后标明“待续做”，可在结果历史中继续。相同模板版本、参数、截止日和快照可复用评分，但文件每次仍校验 SHA。
- 行情源或复权不一致、损坏文件、缺少当日K线、长度不足均单独说明，不拿未来K线补齐，也不冒充“无信号”。

匹配列表标题处显示后台进度或未完成状态。后台结果完成时只更新列表和可选日期，不打断正在操作的图表或关注列表；下次主动选股／翻页使用刷新后的顺序。

## 本地与开源边界

正式检索不访问远程形态捕手，不使用 MCP，不新增 AkShare 下载流程。模板和历史回执使用现有 Store、meta 和不可变文件，数据库表结构不变，Git 更新不覆盖个人模板和研究结果。
