# 交互图计划五线与轴签避让

## 范围与风险

Issue #173，C-23 切片 A，R2 显示修复。基线为 `1c0ddaf`，交付分支为 `lord/tv-chart-slice-a`。

挂起的 GAP H2 计划在原策略周期显示 Entry、SL、SL1、MM 和 2R。SL 与 Gap Floor 分开绘制，2R 沿用快照浅灰虚线。轴签第一行显示价位，第二行显示计划或持仓标签。标签与最新价、EMA 和绘图价签共用现有避让，横线仍落在原始价格上。轴高不足时保留现有优先级，超出可视区的线和价签仍按视口裁切。历史回放沿用计划生效日期和持仓隐藏规则。
