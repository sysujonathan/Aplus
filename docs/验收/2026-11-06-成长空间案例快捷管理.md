# 成长空间案例快捷管理

基于已合并 PR110 的 main，新分支 `codex/growth-quick-case-actions`。R2：只增加快捷入口及本机案例删除；当前仅实现公共下架与恢复，不与删除等同；Google Drive 回收站删除尚未实现。

## 实际交付

- 卡片上常显“···”；原图工具栏有“编辑”和“···”，保留“研究此案例”；详情标题区使用相同入口。最近研究也复用该菜单。卡片菜单与查看图片是独立控件，菜单点击不触发卡片打开。
- 三处都经 `caseCommand` 加载同一案例，再调用既有资料编辑、publish 或上下架流程。弹窗关闭/保存回到原位置，原图缩放、平移与索引保持；标题及列表即时更新。
- 公共写入成员可编辑，管理员可下架/恢复；只读时明确说明限制。公共下架从正常列表、搜索、图谱和随机池移除，仍可由管理员在已下架筛选中恢复。没有“永久删除成功”提示，也不调用 Drive 删除/回收 API。
- 私密案例可编辑、发布或删除本机案例。发布成功明确提示本机原件和个人记录保留，并可直接查看公共版本。公共 publish 白名单及图像校验不变。
- 本机案例库移除经 Store，仅移除当前本机 owner 的案例、关联关系、本机笔记/判断及试炼设置；先在现有 meta 保存该案例的本机恢复资料，原图文件保留。其他本机 owner、已发布的公共原件和账号历史不受影响。没有新增恢复管理页面或永久擦除承诺；删除资料不在普通案例 ZIP 导出范围，完整运行目录的备份才保留这份恢复资料。
- 删除后刷新列表、最近研究、图谱及当前试炼，清除当前查看器/图片缓存；保留的账号历史标记案例不可用，不再提供失效跳转。试炼事前的原图查看仍禁止管理资料以免提前揭露案例信息，完成判断后可用。
- 正式导航、窗口、加载提示与页面统一显示“成长空间”，保留“PA 交易试炼”名称。

## 必要验证

全部使用新隔离 Store、合成图片、内存 Drive 或隔离 WebView，未操作正式账本和真实公共案例。

1. 三入口生产 JS、权限差异、原图编辑缩放恢复、发布反馈/查看公共版本及删除引用清理；私密发布后删除不影响公共原件、个人笔记与判断不上传、其他本机 owner 拒绝；复用管理员上下架反向测试：**3 passed / 1.30s**。
2. 一个新增的短 Edge WebView 模式，仅检查常显卡片菜单、卡片编辑、原图编辑保留缩放、详情编辑和原图查看器移除本机案例后清理，**1 passed / 9.95s**。没有重跑旧的完整 WebView 闭环。
3. 增补即时显示与账号历史不可跳转后，仅重测受影响两项：**2 passed / 0.84s**（与上面的用例重叠，不累计）。另对私密判断已存在时的发布，以及原图文件保留补充断言，单独复测私密边界 **1 passed / 0.69s**。均为同一组用例，不增加独立用例数。JS 语法与差异检查通过。

初次受限进程无法访问测试临时目录（WinError 5），未修改目录权限；改用独立 `.test-pa-growth` 目录运行指定用例后通过。未跑全仓、完整 PA、性能、OAuth 或安装升级测试，未改 CI 规则或门禁。

## 边界

Store schema 9、OAuth、公共协议、账号隔离和冻结策略保持。公共下架是 Aplus 中的可恢复移除，不是撤销 Drive 编辑者的直接读取能力，也不是清空云盘原件。本机案例库移除保留原图和局部恢复资料，不等于永久擦除磁盘文件。真实 Google 多账号和长期实际使用仍沿用既有验收边界，本批不冒称已重验。代码交付、GitHub 必需 CI 和人工批准分别判断；不自动合并、不等 CI。

## PR113 编辑会话收尾

本轮仅修复 reloadCase 的迟到响应：每次打开编辑框生成独立身份，请求捕获案例 ID、actionContext 和 caseSeq，两个 await 后分别核对；关闭、切换或重新打开编辑框后不再采用旧响应。生产 JS 延迟回归先复现 A 覆盖 B，再确认分别延迟 refresh_shared 和 get_case 时 B 的案例、上下文、版本、会话与表单均不变；同时保留 A 从 A1 正常重新加载到 A2 及拒绝丢弃未保存修改的提示行为。只执行该定向回归和操作文案的轻量渲染/语法检查，没有重跑前批 WebView、存储、OAuth 或安装验收。

需求边界更正：公共下架/恢复已经实现；指定公共案例及其专属文件的回收站删除尚未实现，未验证逐文件权限、资源归属及多文件并发/部分失败恢复条件。不宣称“用户已确认下架等同删除”，不实施危险清理。私密功能是从本机案例库移除，保留原图与独立恢复资料，界面及 PR 使用这一准确表述。
