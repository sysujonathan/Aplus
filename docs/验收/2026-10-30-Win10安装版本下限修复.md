# Windows 10 21H2 安装版本下限修复

## 已确认事实

伙伴运行第一版安装包，安装开始前报“此程序不支持当前计算机运行的 Windows 版本”。
用户确认设备是 **64 位 Windows 10 21H2**；原脚本为 `MinVersion=10.0.19045`，
即要求 Win10 22H2，阻止了 21H2（19044），尚未执行数据接续。

Inno 官方说明 MinVersion 不满足时会报错退出；架构不匹配也使用相同的 WindowsVersionNotSupported
提示。因此截图本身不足以判断具体版本或架构，须结合用户确认，而不是直接认定所有 Win10 不兼容。

- [MinVersion 官方说明](https://jrsoftware.org/ishelp/topic_setup_minversion.htm)
- [ArchitecturesAllowed 官方说明](https://jrsoftware.org/ishelp/topic_setup_architecturesallowed.htm)
- [Microsoft WebView2 支持的 Windows 版本](https://learn.microsoft.com/en-us/microsoft-edge/webview2/#supported-windows-versions)

## 最小修复与边界

R2 的安装准入配置修复：最低版本从 19045 调整为 **19044**，保留 x64compatible 架构要求，
即本轮目标为 Win10 21H2 及以后 x64 / Win11 x64。未取得设备信息时曾讨论更老版本的兼容性，
确认实际 21H2 后采用这一更小范围，不将未经实测的 Win10 早期版本一并宣称兼容。

中英文早期报错明确显示版本和架构要求，不再仅显示无法区分原因的通用提示。
不修改 AppId、程序目录、版本指针、WebView2 安装/签名验证、冻结预检、数据识别及备份、
业务代码、依赖锁、Store/schema 或更新审批。不能通过旧安装包的重新下载、管理员权限或兼容模式
修复这个硬编码版本下限；应使用新的修复安装包。
