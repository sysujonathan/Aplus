# PA 公共案例协作与页面精简

基线：已合并 PR105 的 main `8d336b801eda55636863194521542d006ee728d8`；开发分支 `codex/pa-case-collaboration`。本批为 R2 共享写入变更，按用户限定仅执行新增边界与受影响导航/输入检查。

## 实际交付

- 默认案例研究；移除独立首页，导航固定为案例研究、PA 交易试炼、知识宇宙、个人成长。继续研究并入唯一搜索区，收录/拖入/批量/私密切换/图表对照沿用。
- 现有公共详情增加编辑资料、公共留言、修改历史。成员可改他人案例的四项公共资料；原案例 ID、贡献者、截图、完整性校验和引用保持。
- `collaboration-v1` 追加修订/留言/上下架，读取时叠加原始 manifest；不 PATCH 原件。资料显示有效标准术语，知识图谱随公共刷新更新。
- 过期版本拒绝；同时通过预检的修订保留两个分支并显式冲突，正式资料保持分歧前版本。重新加载核对后保存完整资料可解决分歧，不自动最后写入覆盖。
- 公共留言只上传显式输入的纯文本、当前 Google 身份和时间；个人笔记沿用本机个人记录，不迁移公开。
- 目录所有者可确认下架/恢复；普通成员按钮与接口均受限。管理员展开既有筛选选择已下架案例恢复，无独立管理页。下架不删除原始 JSON、图片或留言，并排除正常搜索、图谱及随机题库。

## 最少必要验证

`python -m pytest tests/test_pa_collaboration.py -q --basetemp=.test-pa-collaboration`：**5 passed / 2.70s**（其中一项为 Node 轻量渲染，不重复累加）。使用新隔离 Store、合成图片与内存 Drive 两身份，未读写正式账本或真实 Google 案例：

1. 实际 guarded 编辑接口允许普通成员编辑他人资料；原图字节、原始文件和贡献身份不变；历史保留作者/内容，图谱使用新术语；旧版本及额外原图字段拒绝且不写云端。
2. 同时提交保留并发历史、共同旧资料和冲突；核对后新修订引用双方分支，两身份刷新一致。
3. 留言跨身份可见且不被修订覆盖；账号/本机私密笔记不出现在云端文件；空留言拒绝。补查单条协作记录 404：目录仍可访问时保留全库许可和旧有效缓存，定向复测该用例 **1 passed / 1.14s**。
4. 非所有者上下架/查看下架列表拒绝；所有者下架排除搜索/图谱/随机池，恢复后案例和留言仍在；没有文件被删除；伪造所有者身份拒绝并保留有效缓存。
5. 轻量 UI：默认导航顺序、唯一搜索框、继续研究、空状态提示、管理员入口、留言转义和个人笔记区分。

受本批导航移除影响，原有轻量导航延迟查询检查与拼音输入控件检查均通过；`node --check gui/pa_growth/growth.js` 与 `git diff --check` 通过。既有 UI 夹具只调整首页相关引用，未重跑完整 PA UI 集合。

没有全仓 pytest、完整 PA 专项、性能基准、Windows WebView、OAuth、EXE 安装升级重验；没有自动清理真实测试案例。新增协议未做真实 Google 双账号操作验收，不能将两身份夹具结果称作真实云端多人验收。

## 风险与未完成

Drive 无原子 compare-and-swap，列表可见性或分页延迟可能在后续刷新才暴露分支；本批不承诺强一致性。上下架冲突暂按下架处理，由所有者重新确认。缺失或改写的协作记录导致刷新明确失败并保留上次有效缓存。

信任团队的 Drive 编辑者仍能绕过 Aplus 改删文件，客户端下架不是服务端撤权；旧版不识别新记录，仍展示原始资料及下架原件，团队需要升级。没有 RBAC 后端、审批、图片留言、嵌套回复、通知或复杂合并工具。原完整 Drive scope、Google Testing/审核限制保持。

Store schema 9、OAuth/DPAPI 与会话/权限 epoch、唯一公共目录、冻结策略、行情、回测、账本及发行更新门禁不变。只新增现有 meta 的可重建公共协作缓存，无数据库迁移。自动 CI 和人工评审状态由 GitHub 独立判定，本地通过不代表已满足合并条件；不等待 CI、不自动合并。
