# 桌面同步测试日期基准

基于合入 #187 和 #188 的主线 `ad229b7`。#187 让共享测试日期随运行日更新，#188 的两个跨日增量测试仍把 `2026-11-12` 用作下一天。11 月 19 日执行验收时，基准已经是 11 月 18 日，打包按规则拒绝了日期倒退的增量。 [主线 A acceptance #681](https://github.com/sysujonathan/Aplus/actions/runs/44479726904)

三个测试文件从同一天派生前一天和后一天。跨日增量的时间戳、日历、目录日期与断言使用同一后继日期，旧快照和旧日历使用前一日。改动范围限于测试及本验收记录。

在 Windows 和 Python 3.12 上复现两个原始失败，错误均为“同步源父版本不适用于本次增量”。修复后，两项原用例均通过。桌面同步、版本化同步、交付、CI 选择和安装版发布定向回归合计 295 项通过，冻结源码字节校验通过。

本地用例使用隔离目录和合成行情。GitHub 必需检查、合并后的主线自检和正式发布由远端工作流完成。
