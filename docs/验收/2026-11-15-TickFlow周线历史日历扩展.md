# TickFlow 周线模式历史日历扩展

## 范围与风险

修复任务，R2。基线 `origin/main`：`71b13176a57749776c3d6bafad4248ac20abee4d`（PR #171 已合入）。单分支 `codex/tickflow-weekly-calendar`；交付 SHA 以本文件所属 Git 提交及 PR head 为准，避免自引用。开工已更新 main 并查询活动 PR，未发现同题活动 PR。

只修复 TickFlow 同源日 K 补拉之前的日历准备。`readiness.extend_exchange_calendar()` 仅给 TickFlow 增加专用路由，其余来源保持原实现。`tickflow_calendar.py` 优先保留已有覆盖、只读复用公共日历，仅对仍缺失的日期使用正式休市公告；向前、向后补足但不缩短原覆盖。完整 TickFlow 日历直接返回、不写入；可靠共享日历按原 copy-on-write 机制复制／复用。缺少可靠年份时在写入和行情请求前拒绝，不从价格缺日推测休市。

没有改冻结策略及清单、125 根资格、300 根输入、数据库 schema、BaoStock 行情、GUI 布局或新“同步”功能。没有独立周线接口、周线数据库或周线同步链路。全部价格仍通过现有 TickFlow 日 K 获取／Store 快照／本地周线聚合／质量认证。
