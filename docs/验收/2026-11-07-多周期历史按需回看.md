# 多周期历史按需回看

基于主线 `21442c90cf79ae9bc0138c169343cacab410bf48`。按 R2 验收桌面内嵌图表和会话接口。候选仍使用 300 根策略窗口，日、周、月从同一快照分别回看。周线与月线的首个可能不完整的旧周期由补载重新聚合。每批最多 400 根，距左边界 36 根以内触发。切换标的会重新从首屏范围开始。

分钟图包含 1、5、15、30 分钟和 1 小时。首批显示范围由已取得数据的最近最多 300 根组成；保留同口径且时间戳有重叠的真实数据，每周期上限 2,000 根，仅限当前会话。没有重叠的行情批次保持独立，向左回看无需发新请求。腾讯现有接口最多请求 640 根原生柱，15 分钟和 30 分钟还取决于 5 分钟数据覆盖。长期分钟历史需要可按日期向前查询的数据源或经确认的本地归档。

## 交易员操作

1. 在盘前任务点一个有多年本地历史的日线策略结果。单图及多图都可先看近期，选择多图时只操作要回看的那一格。
2. 把图向右拖动，回看左边的历史。接近已加载数据的左缘时松手。再向左回看，应能看到新增的历史 K 线。重复至快照起点。
3. 记下当前第一根可见 K 线的日期，并在图上画一条趋势线。下一批补齐时，核对可见日期、价格缩放和趋势线端点。分别切到周线和月线，向左回看，再回日线确认日线仍可继续。
4. 切到有行情的分钟周期，回看到最早可用时间。盘中有重叠的后续行情时，核对已回看的分钟位置未被覆盖。
5. 快速切换两个候选，核对旧图的历史不会进入新图。同一标的的历史观察仍以其信号日为边界，既有盘中参考报价另按原规则显示。

## 本地证据

- Windows 上用真实 WebView2、生产图表脚本和 Python 图表接口，使用 2,450 根合成日线。候选截止日在快照结束前 12 根，首屏加载 300 根，六次补载最终达到 2,438 根并停在快照起点。
- 从图表平移触发到完成重绘，六批日线实测 31.4–41.6 毫秒，中位数 37.0 毫秒。样本包含本地读盘、快照校验、跨进程和重绘，属于单图本机计时。
- 原生探针核对每批后视口日期、价格缩放、人工趋势线及撤销栈锚点、默认 EMA20 末值和周期往返。图上 EMA 会使用新补入的左侧数据重新预热，原窗口左缘附近的 EMA 值可能调整。
- 定向用例核对补载区内画线可按原日期保存、重复游标可重试、旧会话不能写入当前图、快照校验失败时不扩充历史。冻结策略输入、正式数据、扫描口径和数据库结构均未修改。
- WebView2 逐个操作八个周期，检查周月快照聚合与真实交易日收盘标签、盘中日线参考更新后保留已补载周月数据、分钟行情窗口前移后保留重叠批次，以及短批次累计。相邻模块定向验收 130 项通过，最终限定内嵌入口后复验历史补载、快照与策略证据 23 项通过。
