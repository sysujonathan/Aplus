# 安装版版本身份与发布校验

## 范围与授权

用户要求立即落实版本编号与验证规则，并继续提交原 PR84。此次属于 R3 发布链路修改：
采用官方 GitHub Release、精确主线提交的 push A acceptance、版本顺序及包字节作为更新门禁，
Windows Authenticode 为可选项；不另建 PR，不自动合并或发布。
不改变 core/config/frozen_manifest、Store/schema、行情规划、策略与 UI 操作方式。
本轮测试仅使用隔离合成数据，未打开、搬移或覆盖正式数据库。

## 行为

- 版本为北京时间日期加当日序号，不以 PR 号、提交数量或可重置的工作流 run number 比较。
  日期、当日序号、发布 sequence 严格一致；构建分配器跨过已发试用包和已有 Release，不倒退。
- 应用、稳定启动器和 Setup 的 Windows 文件版本/产品版本，以及安装版更新界面，读取同一发布身份。
  无精确发布记录的新源码提交显示源码版短 SHA，不再误标为过时的 PR53。
- 官方 stable Release 必须非草稿/非 prerelease；标签、完整提交、元数据地址、安装包名称/地址/大小一致。
  提交必须属于 main，并具有对应精确提交最新一轮 main push A acceptance 成功；PR 检查不能替代。
- 安装前重新核验官方发布、当前已装版本及包大小/SHA256，拒绝降级、内容变化和失效发布。
  Windows 证书不再额外阻断这些经过主线验收的包；微软组件与编译器签名验证保留。
- 发布工具仍由维护者显式执行，要求精确当前 main 与 CI；校验后创建草稿并上传，公开前再查 main/CI。
  构建工作流权限、A acceptance 门禁及测试范围未放宽，不自动公开安装包。
- 早期 .1–.5 试用版保留旧签名规则，首次接入需完整退出后运行新 Setup 升级原安装目录，无需先卸载或搬数据。

## 包与发布边界

本地 .6 为 preview，不是正式 Release：148,860,042 bytes，SHA256
`37f25ba141314a1b95a130a9e5e3b3992e355b6e7b361839026831eceb566916`。
未安装覆盖本机日用程序。用户反馈 Win10 21H2 x64 伙伴实测正常可用；此为用户提供的现场反馈，
不冒充开发者在该设备执行过完整测试，也不外推全部 Win10 版本。

本地演练不等于真实官方线上升级。最终修改需要最新 head 必需 CI 和人工评审，合并后再等
main 精确提交 push 验收成功，重新构建该主线版本并核对实际产物后，才能显式公开正式 Release。
Windows 签名可选，不承诺消除 SmartScreen/安全软件提示；更新信任官方 GitHub HTTPS 与仓库治理，
未实现独立元数据签名、密钥轮换或防止仓库发布权限失陷的安全模型。
