## 范围和交付

用户要求追加到既有 PR101，不另开 PR。开发，R2；基线 main `9f74c295a2ecfb7aefccfe35f68edc03c8ad188f`，分钟绘图阶段提交 `4d52fa5eb60dda2eab634ba7310ce180baf5b227`。本次实现与本文一并提交，最终 head 见 PR。前一阶段的图表证据保留在[分钟绘图验收](2026-11-03-分钟绘图与跨周期坐标.md)，其中“不改行情计算”描述适用于该阶段。

完成标准：减少盘前重复校验/计划构建成本；跨业务标签共用自动行情开关；移除顶栏使用说明按钮。冻结计算、行情口径、交易记录、Store/schema、五策略授权和快拒判据不变。不开新门禁，不扩大 ETF 扫描范围，不增加定时扫描。

## 实现与边界

1. `market.validate_bars`：无时区日期改用批量日格式，带时区仍保持本地日期；有限值检查后直接向量比较 OHLCV，减少临时 DataFrame。缺列、数值转换、重复日期、非有限值、正价格及高低价关系检查均保留，不以省检查提速。
2. `h2_plan.plan_at_end`：默认选择最新待挂计划时，跳过距末柱超过 `TIMEOUT=30` 的旧信号结构重建。这些信号按原生命周期无论先触发/失效还是最终超时，都不可能保持 PENDING；第30根仍完整计算，指定历史 `setup_date` 完整复核。存活候选仍用完整输入，不截断冻结计算或 Floor/MM 上下文。计划层版本仍按文件哈希更新，升级首轮旧扫描缓存按原机制失效，之后恢复复用，无需重新下载历史行情。
3. `AplusMainWindow` 顶栏最左侧放置“自动行情”，与软件更新按钮同一行，盘前/盘后/策略/交易等页均可操作。沿用既有 Store 设置；交易页延迟创建时接入同一变量，避免两份开关状态。控制持仓报价和活动图格连续刷新，不触发全市场更新/扫描，不将实时报价注入历史回测。
4. 关闭开关停止连续请求并使在途结果失效，保留图形。切换新标的仍可一次读取分钟历史；首次失败后可手动“更新K线”重试；开启后恢复原交易日历、盘中/午休/收盘边界。持仓手动“刷新”保留，独立嵌入的交易页保留自身控件。
5. 顶栏不再创建“使用说明”按钮；帮助模块及更新日志入口不删除，说明继续保留在仓库。

既有五门禁的控制器、授权配置、Service 和冻结文件未修改。其他 agent 的 GAP H2 70根候选门禁未直接接入；本轮不把其未复核的全市场倍率视为产品证据。

## 性能证据

环境：本机 Windows 11，Python 3.12.13、pandas 2.5.3、NumPy 2.3.3。全部合成数据；无正式数据库、真实全市场或长期盘中验收。时长受机器负载影响，不作为 pytest 通过条件，也不承诺所有用户相同倍率。

初轮对照中，300/3000根校验中位耗时分别从4.27/22.69毫秒降到2.83/15.82毫秒（约1.51/1.43倍）。最终交付探针复测为3.11→2.15及16.80→12.20毫秒（约1.45/1.38倍），校验环节稳定改善。

完整 Service 扫描为20只×3000根×6策略、每组120次计算，交替前后各三轮、禁用五门禁以隔离本次改动：首轮中位数9.46→9.03秒，耗时减少约4.6%；最终交付探针复测7.96→8.04秒，约慢1.1%。整轮差异仍处于负载/测量波动范围，**未证明稳定端到端提速**；不能把局部收益外推为盘前总耗时承诺。两次的三对均输出一致，但随机样本没有命中，因此不替代包含真实检测器命中的 H2 契约测试；不能据此宣称全市场零漏报或5.5倍提速。若目标是大幅降低整轮耗时，还需另行复核并正式接入策略快拒的性能证据；本轮没有因此冒险修改冻结逻辑或自动授予加速权限。

可复现探针：`tests/premarket_speed_probe.py`，精确加载上述 main 的旧校验/旧H2选择器；随机种子42（校验）、23（扫描），使用新隔离目录保存合成行情及回执。调用示例：

```powershell
python tests/premarket_speed_probe.py --output .test-premarket-benchmark --scan
```

输出目录必须尚不存在；探针不读取用户 runtime，不修改持久授权。重跑只比较当前机器的同轮前后结果，不强求复现绝对秒数。最终可复现探针的结果另存[计时证据](evidence/premarket-speed.json)。

## 交易员验收与未验证项

1. 更新后各业务页均在顶栏左侧看见自动行情；开关一次后切页状态一致，重启记住选择。右上角使用说明消失，软件更新按钮正常。
2. 关闭时打开一个新关注标的，仍能首次看分钟图；没有行情时手动更新可重试。关闭后持续等待不应重复自动请求；开启后按交易时段继续刷新。持仓手动刷新正常。
3. 扫描前后核对同一快照/日期/策略的命中、H2计划价和待挂状态；再次同条件扫描仍复用。升级首轮因计算版本变化可能重算，不能将其当作平稳复用耗时。
4. 日线通道切5分钟、分钟绘图返回日线、保存/重开、切标的及关闭流程复核原PR行为。

正式安装包、Win10伙伴设备和持续盘前/盘中观察尚待人工验收。未覆盖或启动日用安装；提交后不等待/轮询CI，不自动合并或发布。
