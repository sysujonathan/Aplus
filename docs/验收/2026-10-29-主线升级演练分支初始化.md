## 修复

- 候选提交生成后，明确在临时仓库建立/定位 main 到源提交，每次都覆盖已存在 main 的场景。
- 使用 `git switch -C main <历史提交>` 将临时 main 定位到演练旧版。
- 断言历史 HEAD 正确，候选分支仍指向候选提交，然后继续完整的两次升级和桌面启动演练。
- `-C` 仅作用于测试自建的 disposable clone；不用于开发源仓库或正式安装目录。
- 本机复验随后暴露临时目录过长：Streamlit 依赖内的模板路径在展开 8.3 别名后达到 260 字符。
  将一次性演练目录移到 checkout 的父目录，仍使用带空格的真实目录及 8.3 别名，继续验证两次真实启动。
- 启动前失败先输出回执和环境安装日志，再检查进程证据，避免只报告空进程列表。
  新增独立失败探针确认安装错误可见；不降低成功回执、启动确认、进程身份或数据原字节断言。
