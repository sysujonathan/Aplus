# Windows 首版安装包候选

## 目标与边界

R3 安装/发布链路开发。基线 `c74aa302a68894ed9e2b8404a833bf67a8a07303`，独立分支
`codex/windows-installer`。目标是交付可安装试用的首包，保留现有桌面与 TV 界面，旧数据接续、
程序/开发分离、软件内一键下载更新。不是已正式发布或本机日常入口已切换。

core、config、frozen_manifest、Store/schema、策略、正式交易记录未修改。
安装/更新集成使用合成数据、隔离目录；没有打开本机真实业务库、替换日常快捷方式或正式安装。

## 构建与发布保护

PyInstaller 6.22.3、Inno Setup 7.1.1（官方 Pyrsys B.V. 有效签名）；WebView2 引导器核验微软有效签名。
正常安装不要求管理员，不更改系统安全策略或杀毒排除项。无代码签名证书，首包是未签名预览。
正式包构建要求精确 main push A acceptance 成功，正式发布工具还要求可信签名、最终包哈希与大小；
预览包不能进入自动更新。

构建工作流只读、输出试用 artifact，未改 A acceptance 的必需 job/触发/完整测试范围。
尝试配置“有签名密钥时自动发布稳定 Release”被自动审批拒绝，原因是新增仓库写权限及密钥使用未获明确授权。
该补丁未应用，未增加写权限、访问密钥或自动发布；保留为待用户确认事项。
