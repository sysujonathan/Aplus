# 回测统计补齐验收

对应 Issue #168，基线为 `1c0ddaf`，验收对象为本地交付补丁。风险等级 R2，覆盖桌面 GAP H2 历史回执、网页通用回测报告和相邻研究契约。

| 验收项 | 本地证据 |
|---|---|
| 1. 两条链分年可对账 | 2018–2025 年构造报告，两条链各有 80,000 个信号、60,000 笔已结束。每年各 10,000 个信号、7,500 笔已结束，8 年合计分别为 80,000、60,000。各年胜率 33.33%、平均 0.33R。跨年退出测试按信号年归组。 |
| 2. 机会数差和信号保持率 | A 为 4、B 为 3，手算 A − B = +1、B ÷ A = 75.00%。GAP H2 对比行断言和网页实际对比表一致。另验证基线为 0 和缺少信号数时的提示。 |
| 3. 通用持仓统计 | 抽查 1 根（+2R）、4 根（−1R）、31 根（+1R）、2 根（0R）；另有未结束的 700 根。已结束均值 9.5 根，中位数 3 根，盈利中位数 16 根，亏损中位数 4 根。七档笔数依次为 1、1、1、0、0、0、1。网页测试另用三笔已结束 CSV 验证显示和明细入口。大样本按原始记录独立核对均值、中位数、盈亏中位数与所有分桶。 |
| 4. 存量回执 | 网页使用隔离 Store 中的历史格式 CSV 回执进入回测研究页。字段齐全的报告正常显示；缺日期、净收益率、持仓根数的回执分别标注原因，可用 R 仍可统计；缺 CSV 显示无法读取。GAP H2 旧报告的聚合测试保留可计算项目并提示缺 R，SL1／MM 原生按钮路径有 Windows 自动化用例。 |
| 5. 模块测试与验收记录 | 本地命令、性能原始数据和环境限制见 [交付报告](../../fix-168-report.md)。 |

数据为构造回执和隔离测试数据。待 Windows 原生桌面复验、真实交易研究样本复核和长期使用验收。GitHub CI 及人工合并验收尚未发生。
