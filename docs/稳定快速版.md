# 稳定快速版（2026-10-27）

交易员已明确授权五策略在日常启动后以 **ACCELERATED** 为目标，不再要求大规模 SHADOW/CANARY 过渡。MTR、3K、Gap Pinbar、AWIL、Structural Gap 保留 5% 确定性原版抽查；GAP H2 继续完整执行原版。

## 正常启动

本 PR 经人工审批、必需 CI 并合入正式 main 后，关闭已有桌面/网页，在项目目录使用平时启动软件的 `.venv` 明确授权一次：

```powershell
.\.venv\Scripts\python.exe tools\acceleration_settings.py approve --confirm
```

命令只在本机保存当前精确版本授权，不扫描、不联网、不写数据库。未知环境、精确版本不匹配或已有熔断时拒绝写入，逐项报告原因，不扩充白名单。授权保存在 `%LOCALAPPDATA%\Aplus\acceleration.json`，不在 Git 仓库。

之后直接双击原 `启动A.vbs`；原网页入口也加载同一配置。不需要每次设置五组环境变量。启动只读取已有授权，绝不自动生成或续签。没有有效授权时执行原版。

## 确认实际模式

```powershell
.\.venv\Scripts\python.exe tools\acceleration_settings.py status
```

以逐策略 **effective=ACCELERATED** 为实际启用依据，核对 `original_audit_rate=0.05`。OFF 会显示原因，不能只看配置写着 ACCELERATED。桌面启动结果还写入 `%TEMP%\aplus_dashboard.log`，保存在后端 `acceleration_status`。status 只读取冻结代码、授权文件和现有熔断证据，不调用 detector、不写数据库。

原控制器仍核对精确策略、依赖、适配层、Service、环境及相应持久化契约。配置另外绑定启动接入代码、完整 Python/NumPy/pandas 版本和虚拟环境目录。相关变化后旧授权失效，须重新明确授权；不自动替换号码。单策略旧绑定/熔断独立回退；全局配置损坏或启动版本不匹配时不加载该文件。

本机配置和维护环境变量中的任一处 OFF 均优先，旧的 ACCELERATED 环境变量不能顶掉本机关停。其余显式维护模式/授权仍优先，状态工具如实显示。稳定快速配置中的 ACCELERATED 固定保留 5% 原版抽查，不被旧的零抽查环境变量覆盖。门禁异常或输入不可信继续完整执行原版；抽查发现可信结果差异或原版业务异常独立熔断、保留证据。

## 关闭与版本回退

关闭一个策略或全部策略，随后重启：

```powershell
.\.venv\Scripts\python.exe tools\acceleration_settings.py off --strategy MTR
.\.venv\Scripts\python.exe tools\acceleration_settings.py off --strategy all
```

可选名称为 `MTR`、`3K`、`"Gap Pinbar"`、`AWIL`、`"Structural Gap"`。命令只将模式改为 OFF，不换绑定、不复位熔断、不清理数据库。重新批准加速仍需明确执行 approve；显式环境变量 OFF 也需移除后才可启用。

必要时关闭软件，按已有[版本更新](版本更新.md)回执及 `.git/aplus-update/` 代码备份恢复更新前稳定版。维护者可在确认工作区干净后切回升级前 main `587cc5b38175d9b4e7568354b51a4e36dcbd42ef`；不强制重置、不回退数据库。该旧启动器不读取本授权文件，没有另行设置维护变量时执行原版 OFF。
