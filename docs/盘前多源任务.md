# 一键盘前与来源选择

绿色“一键”是原“一键盘前”的分段按钮。左侧执行，右侧单个小箭头打开来源菜单；悬停可查看完整含义，总宽度沿用原按钮，不增加顶栏占用。默认随当前来源使用一个数据源，手动勾选后记住选择，至少保留一个。

选一个、两个或三个来源都可一次执行更新与扫描。板块、周期、策略和目标行情日在提交时固定；下载分别访问所选供应商，每个来源继续遵守自己的连接、间隔和持久冷却。一个来源失败只结束该来源；下载成功的来源无需等待其他来源下载完成，进入本机串行扫描队列。

每个来源的同步和扫描都有独立任务回执，父任务展示各源进度、结束状态与分阶段耗时。可以在任务运行时切换查看来源，结果按来源保存和显示。单源同步失败不会用旧行情自动扫描；部分就绪仍按原完整性规则扫描合格股票，缺口股票继续排除。

三源下载和计算仍独立，只有短暂的本地数据库连接／保存检查点共用顺序，避免多个来源同时抢占写锁。父任务的数量、文字和来源回执在同一检查点保存；单源失败保留已处理数量及错误原因，不再变成“失败0/0”。没有重试行情网络请求、增加连接或改变数据库结构／日志模式。

右下角进度在后台只读获取，界面线程仅显示最近的回执和计时。临时读取失败或显示刷新异常会自动重试，不把它当作任务失败、不清空任务身份；提示“上次进度／正在重试”，不能用继续走动的计时冒充后台有新成果。成功读到真实终态后才恢复任务按钮；某源确实失败仍明确标记。软件未响应、长期无法恢复或真实保存失败不能靠连续点击解决，应保留任务回执排查。

切换来源时先显示已保存的候选；完整性数量在后台只读刷新，显示“正在后台核对完整性”，不在界面线程遍历全市场。重复刷新合并为一次，连续切换只接受最后选择的来源／板块／日期／周期，旧请求不覆盖新结果；刷新失败不显示“已齐”。这些显示摘要不作为真实扫描授权，Service仍执行原有文件校验和资格检查。

桌面看图通过只读连接取已有行情，不再为每次读取行情文件写入数据库日志，与下载少一次写锁争用；快照SHA-256和路径边界校验不变。用户明确保存图表草稿时仍使用正式Store接口。

某一来源“部分完成”不等于这轮三源任务已结束，也不等于数据已齐。当前仍为一轮业务任务：缺口窗口可查看原因，但额外的手工补拉及缺日核验须等整批结束；窗口直接显示剩余来源及阶段，按钮提前禁用、空闲后自动恢复。供应商仍在访问冷却时继续提示等待；价格补拉检查所选来源的冷却，交易状态核验单独检查BaoStock冷却。不插入额外独立下载任务，不循环重试、不绕过限制。

## 一键续做，不从头下载或重复计算

日常默认点击“一键”。更新阶段先核对同来源、目标交易日的目录／日历原始写入校验值，再检查当前日／周输入与行情文件。证据有效、行情已齐的股票直接复用，不建立供应商连接。跨交易日、目录或日历变化、证据缺失时仍执行原有官方准备流程，不用旧目录冒充今天的市场范围。

当前扫描需要的普通价格缺口（未下载、尾部缺失、输入内未知缺日）在本轮来源任务内自动补拉，然后扫描合格标的。已有长历史保留，只请求必要区间与衔接价格锚点；TickFlow 仍每批最多100只，腾讯分页和BaoStock单连接／请求间隔不变。网络失败、限制访问或黑名单立即遵守原有停批与冷却，不以“自动补拉”为由再发一次请求；冷却时可继续扫描本地已核验的合格股票，其余明确待处理。

停牌、新股历史不足、身份异常、坏文件以及当前输入以外的研究历史不自动反复补拉。已成功补拉但相同问题、行情与核验依据未变化时保留“补拉无改善”证据，下一次一键不重复请求；高级缺口窗口可显式重试。完成简报列出行情复用／补拉和判断复用／新计算，仍有问题时显示部分完成，不能承诺供应商没有的行情也能一键补齐。

扫描判断（包括未命中）按快照、策略自身依赖与参数、周期、截止日、公共计算语义保存。MTR自身迭代只让MTR重算；公共指标／计划语义变化仍使相关判断失效。完整阶段回执、缓存和观察记录全部可验证时直接复用整批；否则逐项续做。停止前提交的判断保留，不自动恢复被用户停止的任务，需要再次点击“一键”。手动“更新行情”和“策略扫描”也使用同样的行情／判断复用，显式完整历史或强制重算仍按原入口执行。

PR45的MTR V36.4升级保留完整新冻结版本和输出校验，MTR旧判断必须重新计算。此次已核对的输出校验只影响声明了信号质量字段的策略；未声明这些字段、代码及参数不变的原生3K／GAP，可从已验证的PR47旧缓存迁移到当前完整指纹，避免跟着MTR重复计算。该兼容入口只识别PR45准确校验片段；片段变化、其他公共计算变化、策略自身变化、插件或无法证明兼容的情况仍重新计算，不以版本名称相似放行。

候选列表按股票、策略、周期、交易日显示一个有效结果；新版已完成的未命中判断会替代旧版命中显示，但原始观察记录不删除。黄色“×N”仅统计所选日期范围内不同交易日的命中次数，同一日多次扫描或换版不会变黄。

以上为PR47代码行为，合并和主线验收后还须更新并重新启动本机才能生效；仍运行v44等旧版时，不会因GitHub上已有修复自动改变候选列表。

“终止”停止本次所有来源及后续扫描，已保存快照和已提交判断保留。版本更新、其他下载或研究任务仍需等整次任务结束。没有增加BaoStock并发连接，也没有将ETF持仓按需行情写入盘前股票仓。

整日更新回退时显示“逐股回退”和具体原因，完成简报显示整日保存与逐股回退数量。网络耗时是逐股处理耗时的一部分，两者不相加。

扫描全命中既有判断缓存时仍检查文件SHA与当前资格，省去CSV解析与计算。需解析时，单次扫描用最多64MiB的缓存复用完整已验证数据，不裁剪历史、不省略哈希检查；缓存超出上限淘汰旧帧，任务结束释放。该复用可减少冷核验与日周扫描重复解析，但不承诺所有市场规模下都只读一次。

文件原子写入采用同目录短临时名称，避免在Windows深目录重复拼接长快照名。最终文件路径本身超出系统支持范围仍可能失败，不能承诺任意深度目录均可使用。
