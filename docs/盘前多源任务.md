# 一键盘前与来源选择

绿色“一键”是原“一键盘前”的分段按钮。左侧执行，右侧单个小箭头打开来源菜单；悬停可查看完整含义，总宽度沿用原按钮，不增加顶栏占用。默认随当前来源使用一个数据源，手动勾选后记住选择，至少保留一个。

选一个、两个或三个来源都可一次执行更新与扫描。板块、周期、策略和目标行情日在提交时固定；下载分别访问所选供应商，每个来源继续遵守自己的连接、间隔和持久冷却。一个来源失败只结束该来源；下载成功的来源无需等待其他来源下载完成，进入本机串行扫描队列。

每个来源的同步和扫描都有独立任务回执，父任务展示各源进度、结束状态与分阶段耗时。可以在任务运行时切换查看来源，结果按来源保存和显示。单源同步失败不会用旧行情自动扫描；部分就绪仍按原完整性规则扫描合格股票，缺口股票继续排除。

“终止”停止本次所有来源及后续扫描，已保存快照和已提交判断保留。版本更新、其他下载或研究任务仍需等整次任务结束。没有增加BaoStock并发连接，也没有将ETF持仓按需行情写入盘前股票仓。

整日更新回退时显示“逐股回退”和具体原因，完成简报显示整日保存与逐股回退数量。网络耗时是逐股处理耗时的一部分，两者不相加。

扫描全命中既有判断缓存时仍检查文件SHA与当前资格，省去CSV解析与计算。需解析时，单次扫描用最多64MiB的缓存复用完整已验证数据，不裁剪历史、不省略哈希检查；缓存超出上限淘汰旧帧，任务结束释放。该复用可减少冷核验与日周扫描重复解析，但不承诺所有市场规模下都只读一次。

文件原子写入采用同目录短临时名称，避免在Windows深目录重复拼接长快照名。最终文件路径本身超出系统支持范围仍可能失败，不能承诺任意深度目录均可使用。
