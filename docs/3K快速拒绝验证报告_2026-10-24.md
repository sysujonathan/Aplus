## 等价性证据

### 多日期真实行情

使用源仓只读 BaoStock 快照，300 只股票、5 个历史交易日，共完成 1,493 次合法前缀对拍：

- 快速拒绝：970 次；
- 门禁通过、执行原版：523 次；
- 完整 payload 或机会身份差异：0；
- 门禁拒绝但原版出正式信号：0；
- 原版业务异常：0；
- 熔断：0。

这五个固定横截面没有 3K 正式信号，因此不能单独作为充分证据。

### 真实正式信号专项

为避免“零信号零差异”，另对 1,211 只真实股票的可见历史信号行进行搜索，并按信号当日重新截断行情、重新准备指标和正式 payload：

- 原计算窗口候选行：66；
- 按当日前缀可复现的正式信号：60；
- 60 个正式信号全部满足门禁必要条件；
- 完整 payload、日期、Entry、SL、TP、评分和机会身份误拒绝：0。

其余 6 行在按当日前缀重算后不再是正式信号，原因是当前 300 根窗口与当时输入窗口起点不同；没有把它们冒充正式命中。

### 合法生成数据与异常语义

300 份、125—300 根合法生成 OHLCV 未发现门禁拒绝但原版出信号的反例。代码测试另覆盖：非法价格、日期错序、公共指标改变 OHLCV、阳线指标不一致、版本或环境变化、缺少人工授权、原版业务异常、差异熔断、缓存隔离和 BaoStock/TickFlow 双源。

未在真实行情中观察到原版业务异常；真实异常等价仍属于静态审计和受控测试证据。CANARY/ACCELERATED 未抽样拒绝样本仍存在与 MTR 同类的理论异常时点差异，因此正式启用前必须先完成目标全池 SHADOW。

## 性能

### 3K 检测器局部模型

1,493 次真实前缀的原版 3K 累计为 27.016 秒；门禁累计 0.271 秒。按 970 次拒绝直接跳过、523 次门禁通过后执行原版计算，预计为 9.891 秒，局部减少 **63.39%**。

这是基于逐样本实测组成的检测器模型，不是 Service 墙钟。

### 六策略真实短历史 Service

60 只真实短历史、六个策略、三轮交错顺序：

| 模式 | 冷扫描中位数 | 相对 OFF | 业务摘要 |
|---|---:|---:|---|
| OFF | 12.343 秒 | 基线 | 一致 |
| SHADOW | 10.528 秒 | -14.7% | 一致 |
| ACCELERATED（隔离授权） | 11.715 秒 | **-5.09%** | 一致 |

三轮绝对值波动较明显，SHADOW 快于 OFF 是机器噪声而非算法收益；可信结论是该 60 股样本中 43/60 被安全拒绝、3K 原版调用减少 43 次，六策略墙钟中位数约改善 5.1%。它不是全市场或一键盘前承诺，也不与 MTR 的历史百分比直接相加。

## 正式启用前条件

1. 在最终合并后的 main 和目标 Windows 环境重新生成绑定号。
2. 对正式质量门禁后的全可扫池运行 SHADOW，并逐股核对目标日期有效性。
3. 补充真实 TickFlow、约 2,800 根长期仓和多交易日持续运行。
4. SHADOW 保持零差异、零熔断后，另行申请小比例 CANARY；生产默认仍为 OFF。
5. 任何可信差异或原版异常立即停止启用申请并保留证据。

## 与其他策略 PR 的关系

本 PR 不依赖其他未合并策略加速，但各 PR 都必须最小修改 `workbench/service.py`。后合并的 PR 应基于当时最新 main 重新整理公共接入点、重跑 MTR 和已合入策略专项，并重新生成所有受影响绑定；不得直接用冲突解决覆盖前一策略。
