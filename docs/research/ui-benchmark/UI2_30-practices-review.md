### 推荐优先完成的高频体验闭环

1. **盘前**：九宫格→一套工具栏→活动图格→多图布局/恢复→选股后不丢状态。
2. **盘后**：净R/持仓K线/TOP样本→点击样本→当时可见K线→回到统计。
3. **策略**：选中实验→查看差异结果→定位原因样本→保留冻结口径。
4. **交易**：查看账户与总风险→持仓详情/纪律→保存/确认，不让显示假数据。
5. **PA 成长**：粘贴截图→保存→关键词搜索→原图研究→从当前K线打开对照，不新增一级入口。

## 三、需要人工决策的议题

- [ ] Q1：主导航是否保留五大领域，并撤下“历史案例对照”一级入口？
- [ ] Q2：九宫格是否认可“一套工具栏 + 活动图格”的架构方案？
- [ ] Q3：多图自定义布局先做常用模板与状态恢复，还是直接做自由拖拽？
- [ ] Q4：盘后优先改统计下钻，还是先改新建回测表单？
- [ ] Q5：交易管理的首屏，资金、总风险敞口和日历谁是第一优先级？
- [ ] Q6：PA 成长空间是否以“案例快收/快找”为最高频主线？
- [ ] Q7：哪些功能必须真人操作实测后才能写入 Codex 开发验收？

## 四、明确不推荐的方向

- 不增加必经的炫酷首页，不让图表失去视觉中心。
- 不把所有模块改成统一的卡片 Dashboard。
- 不把现有 Tk/WebView 一次性全面重写。
- 不把策略只读证据和个人画线放入同一同步删除机制。
- 不把 PA 相似度当成交易建议，更不自动合并相似K线截图。
- 不用收藏数量、回测盈利自动评判PA掌握度或纪律。
- 不为了竞品具备订单流或自动交易而把Aplus变成不同类型产品。

## 五、下一步证据补拍要求

- **盘后回测**：报告首页、持仓K线/净R、双报告、样本K线
- **策略迭代**：实验选择、对照结果、差异样本K线
- **交易管理**：资产/风险/持仓/资金流水/收益日历
- **PA 成长**：正式版首页/案例收录/搜索/研究/权限异常

## 六、建议 PR 顺序与门禁

1. 设计规范与主框架/盘前试点；2. 多图工作区专项 Issue92；3. 盘后及策略研究体验；4. 交易管理及成长空间。每阶段均人工评审、回归保护和版本恢复验证。

不改变冻结策略、回测计算、交易账本、现有权限；不等待CI阻止PR人工评审，不擅自合并。
