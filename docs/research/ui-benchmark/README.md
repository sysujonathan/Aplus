## 证据使用规则
1. 公开截图只证明可见界面；不自动证明真实交互和设置保存。
2. Aplus 原型不等于正式版实拍；当时的代码推断需要以最新版本重验。
3. 分清【竞品事实】【产品建议】【已经开发】【当前仍需验证】。
4. 用 Issue #103 归集研究结论，另开专项 Issue/PR 实施；不自动合并，保留团队人工验收。
