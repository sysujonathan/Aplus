# A+ 图表工作台高保真原型

直接打开 `index.html`。原型不连接网络，不写运行仓，也不修改交易记录。

## 原型状态

- `index.html`：策略候选进入单图后的默认交易员工作区。
- `index.html?state=alert`：本机收盘提醒设置。
- `index.html?state=object`：图形样式、坐标和可见性设置。
- `index.html?state=replay`：K 线回放状态。
- `index.html?state=snapshot`：干净快照预览。

页面内也可以直接点击闹钟、回放、相机、对象树、左下显隐和移除按钮体验状态切换。交互按 TV 的操作习惯实现：

- 滚轮以鼠标所在K线为锚缩放，主图区按住左键拖动平移；底部时间轴左右拖动改变K线密度。
- 右侧价格轴按住左键上下拖动改变纵向比例，双击价格轴恢复自动刻度。
- 收藏栏左侧六点抓手可拖动，位置保存在浏览器本机；收藏工具点击后在图上落点，双点工具依次选择起点与终点，多段折线逐点落位并双击完成。默认每次完成一个图形后回到十字光标，不连续绘图。
- 人工标绘单击选中并显示快捷栏，双击打开该工具自己的样式、坐标和可见性设置；颜色用色板选择，线宽和线型可直接设置，上下箭头可调大小与透明度。
- 选中图形后可拖动整体；拖动蓝色圆形端点可调整关键结构。磁铁开启时，靠近K线的端点会吸附该根K线的开、高、低、收价格。
- 人工标绘按标的保存在浏览器本机，下次打开原型仍显示；GAP H2 等策略证据保持只读。
- 左侧放大和缩小按钮进入框选状态，拖出自定义区域后改变横向K线密度与纵向价格范围；Esc 取消当前画图。
- 顶部相机优先把当前缩放范围的完整图表 PNG 复制到系统剪贴板并提示；浏览器未开放图片剪贴板时进入预览保存。

## 数据与边界

主图嵌入的是 Aplus 本机已保存的 `sz.002259` BaoStock 前复权日线中 2026-06-22 至 2026-09-30 的公开 OHLCV 数据，仅用于本次静态视觉核对。原型不读取持仓、计划、提醒或其他个人记录。

5 分钟、1 小时和 4 小时入口以不可用状态展示。Aplus 当前没有自动分钟行情源，因此原型不会用日线拆分或演示数据冒充分钟 K 线；Bar Count 同步显示“5分钟行情接入后可用”。

## 本轮需要确认的视觉口径

- 使用交易员当前 TradingView 主题：白色上涨 K、蓝色下跌 K、黑色背景、橙色 EMA20。
- GAP H2 缺口区保持蓝色虚线空心框、蓝色实线下沿和带白底的蓝色 `Gap` 标签。
- BO、H1、H2、MM low、Gap Floor 的引线和标签继续使用灰白中性色。
- 策略证据只读，人工画图与提醒可编辑并随标的保存。
- 策略匹配和自选是右侧导航；选中标的后留在同一张可操作主图，不再跳入第二套图表界面。
