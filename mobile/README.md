# Aplus 盘前 · 移动端（PWA）

三层架构的第三层：**服务端每晚备好数据，手机只负责看。**

- 服务端（云端/桌面端）跑一键同步 + 策略匹配，导出只读快照包（契约见
  `workbench/snapshot.py`，PR #129）。
- 本应用只读快照包：按策略分组列出命中标的、入场/止损/目标等计划价位，
  快照包带了候选图时点开卡片直接看 K 线图。
- 本应用不做本地扫描、不连行情、不写任何数据。

## 本地/局域网预览

```bash
python tools/export_premarket_snapshot.py                 # 导出快照包（默认带候选图）
python tools/serve_mobile.py                              # 自动取最新快照包
# 打开 http://127.0.0.1:8765/
```

## 装到手机上（iPhone）

1. 用 Safari 打开部署地址；
2. 分享 → **添加到主屏幕**；
3. 桌面出现「Aplus盘前」图标，点开全屏，就是昨晚的匹配。

**约束（必须知道）**：iOS 的“添加到主屏幕 + 离线外壳”需要 HTTPS 安全
上下文；局域网 `http://192.168.x.x` 只能当普通网页打开，装不成 APP。
正式分发需要把外壳与快照包放到 HTTPS 托管——托管与行情数据长期存储的
选型见团队的存储/托管评估结论（评估中），本目录不预设结论。

## 文件

- `index.html`：单文件应用（列表 + 图表查看），兼容 #129 v1 快照契约，
  也能读旧版扁平快照（无图时不显示看图入口）。
- `manifest.webmanifest` / `sw.js` / `icon-*.png`：PWA 外壳。外壳缓存
  优先；`data/` 下的快照永远走网络，不许拿昨天的数据冒充今天。
- 服务端：`tools/serve_mobile.py`（只读、GET-only、禁目录穿越）。
