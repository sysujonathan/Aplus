## 字阶与密度

Tk 正数 pt、Microsoft YaHei UI，缺字用系统中文回退。Consolas 用于现有纯数字用时和技术计数。Web 用等值 CSS pt 与等宽数字。px 为 96 DPI 逻辑单位，Tk 的 padding 和行高随显示比例取整一次，正数 pt 由 Tk 缩放一次。

| 角色 | 沿用与变更 |
|---|---|
| 次要说明 | 沿用 9pt。变更：匹配摘要及日历细项 8→9pt；底栏 Consolas 10→中文 9pt，改善混排 |
| 表体与表头 | 沿用 紧凑 9pt、普通 10pt、持仓表 11pt；表头同阶粗体。变更：回测表体 11→10pt、表头 13／11→10pt，给风险列留宽 |
| 控件 | 沿用 常规 10pt、密集 9pt。变更：迭代和回测常规控件 11–13→10pt，消除跨页尺寸跳动 |
| 标题 | 沿用 面板 11pt bold、分析小标题 10pt bold。变更：策略结果 10→11pt、回测主标题约 14–15→11pt，统一分区层级；成长首页 31–43px→16px（12pt） |
| 关键指标 | 沿用 资产及回测主指标 21pt bold、账户明细 11pt bold。变更：成长数字 36px→28px（21pt），同阶阅读 |
| 间距 | 沿用 4px 紧邻、6px 密集组、8px 组件间距、12px 分区内边距。变更：顶栏 5→4px，成长按钮 14×9→8×4px，统一横向节奏 |
| 行高 | 沿用 盘前 26px、回测主表 32px／分析表 25px、持仓 68px／清仓 34px；DPI 下至少达到字体行距加 6px，保持原覆盖按钮与滚动 |

变更：盘前一键 bootstrap success→ACCENT，扫描和更新的蓝底→CONTROL_BG，终止在可用时采用 UP 前景，休市说明 #888888→MUTED。让一键承担主操作层级，并与盘后主操作一致。导航自动行情保持原开关符号，选中使用 SELECTION。

任务状态由现有文字区分。普通、进行中与完成用 TEXT 或 MUTED，空态、无信号、未成交、暂无报价用 MUTED，部分完成和警告用 REPEAT，失败和危险操作用 UP 加原文字。变更：交易导入与对账错误、速算校验 DOWN→UP，成功回执 UP/DOWN→TEXT，以便和真实盈亏区分。旗标沿用用户自选颜色与命名。市场字段和风险线按业务角色单独读色。
