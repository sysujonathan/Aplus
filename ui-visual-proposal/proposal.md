## 基线与验证边界

本地分支与缓存 origin/main 同为 5ec76913551b90b994f4daa8effd530238e323eb。开工已查 GitHub 活动事项，#173 的计划线和 #169 的研究记录分别保留原归属。GitHub 比较确认远端 main 领先 2 个提交，变更文件中只有 toolbar.py 属于本审计所引界面文件。本报告证据行号以本地基线为准。共享 Git 元数据只读，fetch 无法写 FETCH_HEAD。本地目录初始为空，三份交付从头制作。

[原型](prototype.html) 连续展示三个桌面视口，采用固定的桌面空间关系；所有行情、账户和回测数字均为虚构。原型只覆盖三种代表性静态状态。形态匹配、图表菜单、交易弹窗及另两个模块都在审计和规范范围内，未另做展示屏。本轮按 R0 执行文件范围、HTML 结构、三屏、内部 SVG 引用、离线性、Markdown 链接及 23 项冻结 SHA-256 静态检查。Chromium 启动受环境的 WebGL 策略配置阻断，浏览器渲染及目视排版未验。代码测试、真实数据、Windows Tk 实机、GitHub CI 与长期使用均未执行，用户视觉验收待开展。
