# A · PA 交易工作台

本地运行的人机协同工具：同步行情、匹配原有策略、跳转 TradingView、保存人工计划、回测研究、注册新策略。**不自动下单，不自动改策略，不打开旧项目数据库。**

当前版本 **1.1.4**：交易管理保持 2×2 单页，按 1:3 高度展示持仓/已清仓与资金账户/收益日历。已清仓支持一次粘贴最多 6 张平安证券手机截图，在本机离线识别后进入可编辑预览，确认前不写账本；跨截图重叠会去重，已存在的完整重复记录会被拒绝。资金账户以券商总览方式只读展示资产、仓位和盈亏，支持资金账号脱敏及一键隐藏金额；只有利息、分红、红利税、转入转出及自定义资金调整可维护。买入批次可补录税费合计，收益日历可切换月/年及前后期间，月视图固定六周高度。数据库平滑升级到版本 8，不删除行情、信号、关注、计划或既有交易记录。见 [交易管理账本升级](docs/1.1.4交易管理账本.md) 与 [多图工作区说明](docs/1.1.2多图工作区.md)。

持仓右键或编辑窗口中的“查看持仓图”，显示最新本地日线、EMA20、实际买点、单条综合成本及已保存的止盈止损线；复权坐标缺少参照时后台只读核验不复权收盘价。查看或编辑已有持仓不会自动改用新的扫描计划，修改价位后须先确认保存。

## 启动

交易管理每次进入默认隐藏资金账号、账户金额及日历盈亏，点右上角“显示”仅在本次查看时展开。自动行情在交易时段每 15 秒刷新，午休／休市暂停；历史日历未覆盖今天时使用已公布的 2026 年交易所日历，节假日显示“休市”，不要求补收益数据。详见 [交易管理账本说明](docs/1.1.4交易管理账本.md)。

交易管理的盈亏日历现按账户每日盈亏展示，日期固定中性色、金额单独着色；完整成交可结合历史行情逐日计算，资料不足不记为零。支持连续粘贴券商月日历截图（最多六张），缩略图立即显示、后台排队识别，集中核对后导入；券商数据优先，见 [交易管理账本说明](docs/1.1.4交易管理账本.md)。

- **Web 工作台（调试/日常）**：双击 `启动A.cmd`，浏览器打开本机 `http://127.0.0.1:8517`。关闭网页不会丢失记录，也不会停止正在运行的任务。
- **桌面工作台（工程 A 界面对齐，待用户验收）**：双击 `启动A.vbs`。顶部切换业务板块；盘前页包含市场范围、行情更新、策略扫描、横向策略导航、多股 K 线、候选清单及关注列表。点右上角关闭只会隐藏到系统托盘；双击托盘图标恢复，右键托盘图标选择“退出”才会真正结束。沿用 Aplus 的 Service/Store；不自动迁移旧工程数据。见 [桌面验收说明](docs/桌面GUI对齐验收.md)。

无需配置数据路径。首次启动会自动在当前用户的本机应用数据区建立 `Aplus/runtime`，后续更新代码、重新拉取或切换分支仍复用这份数据。BaoStock 沿用原历史初始化逻辑；TickFlow／腾讯日常更新先准备当前日／周扫描所需区间，更早研究历史可显式补拉，完成后只补缺口和新交易日。旧版本若已在项目内保存数据，会继续沿用原目录；`A_WORKBENCH_HOME` 仅保留给迁移、便携运行和自动测试等高级场景。

换电脑或运行环境缺失：安装 Python 3.12 或以上后运行 `setup.cmd`。依赖安装需要网络。当前交付环境使用 Python 3.12；其他版本需重新验收。

## 从这里开始

盘前可切换 BaoStock、TickFlow、腾讯三个历史来源；各自保存目录、覆盖、行情快照及质量回执，扫描／回测使用所选来源，不拼接价格，不覆盖旧研究。BaoStock／TickFlow 使用前复权，腾讯使用不复权，跨除权信号及收益不能直接比较。交易管理报价腾讯优先，仅缺失／盘中滞后标的向新浪补查，与历史同步独立。扫描前核验新增进度、逐股停止及重启复用，修正旧缓存首次核验被误显示为“排队中”的问题。见 [腾讯报价与扫描核验](docs/腾讯报价与扫描核验.md)。

TickFlow 备用路线支持按日／周策略实际输入区间核验：历史未知缺口不再使整股行情被丢弃；影响当前扫描的缺口逐股排除并明确显示部分结果。更新后的黄色“完整性 / 补拉”入口可查看原因、定向补拉及复检。目录、日历、快照与覆盖按来源隔离，不拼接 BaoStock 和 TickFlow 的历史价格，详见行情恢复说明。

完整性窗口可直接切换已核验的日线／周线回执，不需要重新下载行情。默认补拉以所选周期是否就绪为准，更早历史另列；根数不足不进入反复补拉队列。当前备用源与全市场历史证据库是两项独立交付，见 [当前扫描备用源验收](docs/TickFlow当前扫描备用源.md)。

- [行情恢复与数据源](docs/行情恢复与数据源.md)：BaoStock 连接保护、TickFlow 前复权独立同步、公开停牌证据和持仓报价。
- [协作分工与开发基线](docs/协作分工与开发基线.md)：双方职责、公共接口提案、本地接入与验收记录。
- [给交易员的使用说明](docs/使用说明.md)：三个使用场景、首次运行、回测含义。

## 原策略保护

桌面「策略迭代」第一版提供 GAP H2 初始止损对照：选择已有盘后回测，保持同一入场和 MM，比较 SL1 与候选 C 止损；实验独立保存、支持差异复盘和历史对比。候选规则 V0 只定位低点抬升段，不等于已验证强突破。见 [策略迭代 V1](docs/策略迭代V1.md)。

桌面「盘后回测」已接入 GAP H2 日线历史执行回放：次日计划逐日更新，触发与模拟成交分开统计，提供 Top 盈利／亏损样本和逐笔 K 线。高级设置只作用于本次研究；现有 Web 固定价回测保持原入口。使用方法、保守成交口径与验收边界见 [盘后回测 V1](docs/盘后回测V1.md)。

GAP H2 收盘图现按“次日挂单机会”显示每日 Entry、SL1、风险与 MM 收益；候选保持当日计划，关注随最新收盘核验原形态。详见 [GAP H2 挂单计划](docs/GAP%20H2挂单计划.md)。

`core/strategies/` 内的 12 个 Python 文件从原 A 仓库提交 `6bc1b9e1800d1523118fc862f3791edb8e7faa0f` 原样复制。策略注册表、计算器、评分依赖和配置一起冻结。`frozen_manifest.json` 记录逐文件 SHA-256；启动与研究时检查，变动就停止。新版外围代码在 `workbench/`，不是原扫描器的拼接。

## 验收

双击 `验收检查.cmd`，或运行 `.venv\Scripts\python.exe -m pytest -q`。测试使用独立临时目录，不打开正式运行记录。CI 使用同一套检查。

请勿把 Aplus 本地数据仓当作缓存清理：这里有行情历史、自己的计划、研究结果及策略版本。停止按钮只停止任务，不删除数据。停止整个服务可以在 PowerShell 中运行 `停止A.ps1`。
