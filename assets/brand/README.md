# APLUS 品牌资产 v1

本目录是2026-11-01已选PA款式的正式矢量资产。用户已委托负责人确认几何、字距、颜色和尺寸；本轮把同一 ICO 接入 Windows 应用与安装资源，尚待合并、构建和发布。正式使用规则和验收边界见[唯一品牌规范](../../docs/APLUS品牌标识规范.md)。

- `master.svg`：唯一几何主稿，PA和APLUS均为路径；透明负空间，无位图/外链字体。
- `symbol-light/dark.svg`：浅底黑标／深底白标，保留杏橙；`symbol-black/white.svg`：纯单色。
- `wordmark-*`、`lockup-horizontal-*`、`lockup-vertical-*`：字标与横/竖组合，主题分别导出。
- `app-icon.svg`、`aplus.ico`：黑色圆角应用容器，ICO含16/24/32/48/64/128/256七帧。
- `png/`：符号/单色/应用图标各16/24/32/48/64/128/256/512/1024。
- `manifest.json`：主稿与所有出口的SHA256、字节数、工具版本、参考图哈希及已批准资产基准状态；不代表本机已安装。
- `preview.png`：资产组合预览及实际16/24/32/48/64像素行；不是软件已接入截图。

仅修改主稿几何，再运行`tools/export_brand_assets.py`重建全部出口，不手工修PNG/ICO。构建工具依赖`resvg-py==0.5.0`与清单记录的Pillow版本；安装到独立工具环境即可，不加入运行依赖。脚本从任意工作目录解析本仓资源。根`icon_aplus.ico`是生成`aplus.ico`的逐字节兼容出口；以后重建资产时同样复制更新，`tests/test_brand_runtime_icons.py`会拦截两份图标不一致。

字形来源是用户选定展示稿的人工轮廓重建，未调用或宣称购买某商业字体授权；交接未提供原生成图权属文件。本轮不对商标注册或原稿权利作额外保证。颜色为平面工程校准，精确几何/色值在后续用户委托的负责人审阅中确认，不将此追溯表述为交接原稿已有HEX批准。
